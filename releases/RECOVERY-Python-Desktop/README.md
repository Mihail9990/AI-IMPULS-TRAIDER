# RECOVERY для Windows

Python ведёт цепочку RECOVERY через MetaTrader 5. В терминале работают два советника. RecoveryPythonVerifier сообщает Python о позициях, ордерах и истории. RecoveryPythonSL переносит стоп-лосс на цену входа при достижении заданного порога и подтверждает перенос. Управление и настройки доступны в локальном пульте Windows.

## Установка

1. Скачайте [установщик для Windows x64](./RECOVERY-Python-Windows-ab6028a8a69de19a.zip) и сверьте SHA-256 по [контрольным суммам](./RECOVERY-Python-ab6028a8a69de19a-SHA256.txt).
2. На компьютере должны быть установлены MetaTrader 5 и полный Python 3.13 x64 с Tcl/Tk. Библиотеки MetaTrader5 и NumPy входят в комплект.
3. Распакуйте ZIP, прочитайте `README_RU.txt` и запустите `Install.cmd`. На новом компьютере в инструкции показано, как прикрепить обоих помощников к графикам и загрузить их пресеты.
4. Откройте ярлык «RECOVERY — Пульт управления», проверьте настройки и нажмите «Старт». Выберите «Ждать рыночную позицию» для сопровождения ручных входов или «Ждать триггерный STOP» для поддерживаемого отложенного ордера MT5.

В режиме «Ждать рыночную позицию» после подтверждённого ручного закрытия Python отменяет оставшийся встречный STOP этой цепочки. Если повторный подхват включён, следующая ручная позиция может открыться и до подтверждения отмены. Python сверяет результат отмены и начинает новый цикл с первой ступени. Если встречный STOP успел исполниться, Python сверяет исполнение и сопровождает образовавшуюся позицию. «Отключить повтор» в активной цепочке прекращает подхват последующих ручных входов.
