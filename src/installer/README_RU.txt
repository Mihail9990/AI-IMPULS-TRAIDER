RECOVERY для Windows — локальный пульт Python и два помощника MT5

Что потребуется

Windows x64, установленный MetaTrader 5 и полный Python 3.13 x64 с Tcl/Tk и pythonw.exe. Сборка проверена на Python 3.13.17. Полный Python для Windows доступен на python.org/downloads/windows/. При выборе компонентов оставьте Tcl/Tk. Если Python уже установлен, можно проверить окно тестовой командой py -3.13 -m tkinter и закрыть его.

Работающий терминал должен использовать тот же счёт, сервер и точное имя символа, что и настройки RECOVERY. Установщик работает локально. Библиотеки MetaTrader5 5.0.6231 и NumPy 2.5.5 входят в ZIP. Пароль от счёта вводится в самом MT5.

Перед обновлением прежней установки

1. Сверьте открытые позиции и заявки в MT5. Перед переходом завершите прежнее сопровождение и дождитесь подтверждённого плоского состояния. Если у прежнего пульта есть режим ожидания, отмените его и поставьте стратегию на паузу.
2. Для перехода с прежней архитектуры снимите основной RecoveryTrader и прежние наблюдатели со своих графиков. Закройте прежний пульт, остановите его веб-панель и отдельный экземпляр Caddy этой установки. Его исполняемый файл находится в %LOCALAPPDATA%\AI-IMPULS-RECOVERY\control\proxy\caddy.exe. Другие экземпляры Caddy могут обслуживать другие программы.
3. Для обновления уже установленной версии Python дождитесь пустого цикла, нажмите «Стоп», дождитесь подтверждения и закройте пульт. Супервизор может продолжить работу в фоне. Выход из сеанса Windows и повторный вход до открытия пульта освобождает его блокировку.
4. Если установщик обнаружит другую версию EX5, запишите имя этого помощника. При пустом цикле и остановленном контроллере снимите его с графика, закройте MT5 и перенесите именно этот старый EX5 из MQL5\Experts\RECOVERY-Python в отдельную резервную папку. Повторите Install.cmd. Пресеты и локальную базу сохраните на месте. Когда обновление закончится, вновь откройте MT5, подключите обновлённого помощника к его графику и загрузите сохранённый .set соответствующей роли. Сверьте настройки обоих помощников перед запуском пульта.

При переходе со сборки c89c953f211f01bb обновляется RecoveryPythonSL.ex5. Сохранённый RecoveryPythonSL.set подходит для новой версии на том же счёте. RecoveryPythonVerifier.ex5 и его пресет можно оставить на месте.

При обновлении со сборки 98fe241ccd57a411 оба советника и их пресеты совпадают с поставляемыми. Установщик сверяет их содержимое и оставляет на месте.

Установка

1. Сверьте SHA-256 скачанного ZIP со значением в сопровождающем файле SHA256.txt. В PowerShell это делает Get-FileHash -Algorithm SHA256 .\имя-файла.zip. Распакуйте ZIP целиком в локальную папку. Запустите Install.cmd от имени обычного владельца терминала.
2. Установщик использует сохранённый control\python-v1\machine.json. Для перехода с исходного RECOVERY он сверяет настройки терминала с profile и role-session. На новом ПК консоль попросит полный путь к terminal64.exe, каталог данных MT5, login, сервер, символ и отдельный Magic. Каталог данных открыт в меню MT5 «Файл → Открыть каталог данных». В нём должны находиться MQL5\Files и каталог MQL5. Номер счёта, параметры брокера и приватные файлы остаются на этом ПК.
3. Можно заранее передать локальный JSON командой Install.cmd --binding "C:\путь\binding.json". Для первой установки в нём нужны terminal_exe и data_dir (абсолютные пути), server и symbol (строки), login и magic (положительные целые). Привязка двух помощников создаётся на месте. При существующем machine.json установщик сохраняет прежнюю привязку. Install.cmd --verify-only проверяет распакованный комплект без установки.
4. Дождитесь сообщения «Готово». Приложение помещается в %LOCALAPPDATA%\AI-IMPULS-RECOVERY\control\python-builds\<сборка>. Конфигурация, стратегия в SQLite, результаты и приватная очередь находятся отдельно в control\python-v1. Повтор установки готовой версии сверяет файлы. Для разных Windows-пользователей устанавливайте комплект от имени каждого владельца.

Подключение двух графиков

1. В MT5 обновите «Навигатор → Советники». Откройте два разных графика одного настроенного символа на этом счёте.
2. На первом графике прикрепите RECOVERY-Python\RecoveryPythonSL. В его входных параметрах нажмите «Загрузить» и выберите %LOCALAPPDATA%\AI-IMPULS-RECOVERY\control\python-v1\presets\RecoveryPythonSL.set. На вкладке «Общие» включите «Разрешить алгоритмическую торговлю». Этот помощник изменяет SL привязанной позиции.
3. На втором графике прикрепите RECOVERY-Python\RecoveryPythonVerifier и загрузите RecoveryPythonVerifier.set из той же папки. На вкладке «Общие» оставьте «Разрешить алгоритмическую торговлю» выключенным. Этот помощник проверяет данные и историю MT5. Настройки Login, Server, Symbol и PythonScope должны совпадать между графиками. Названия параметров в диалоге — ExpectedLogin, ExpectedServer, ExpectedSymbol, PythonScope.
4. Если нужна работа стратегии, проверьте разрешения алгоритмической торговли в MT5 и параметры внешнего Python API. Включение этих разрешений выполняет владелец. На основном графике управление стратегией ведёт Python.

Работа с пультом

Помощник проверки сообщает локальному процессу Python о торговых событиях MT5. Получив уведомление, Python перечитывает состояние и проверяет нужную историю исполнения. Периодическая сверка продолжает работать, если уведомление пропущено. Прибыль и убыток смотрите в истории счёта MT5. Пульт показывает ход цепочки без расчёта денежных итогов.

Торговый процесс сначала выполняет сверку RECOVERY. У торгового процесса RECOVERY обычный приоритет Windows. Окно пульта и служба, которая записывает состояние и квитанции команд, работают в двух отдельных процессах с пониженным приоритетом. После его перезапуска пульт получает новый сеанс. Если результат старой команды остаётся неподтверждённым, проверьте текущее состояние. Такие команды автоматически не повторяются.

Откройте ярлык «RECOVERY — Пульт управления». Пульт покажет связь Python и MT5, счёт, сервер, символ и режим. «Старт» включает обработку после проверки привязки. Рыночное и триггерное ожидание выбираются отдельными кнопками. Рыночное ожидание возобновляется после подтверждённого ручного закрытия позиции и отмены последнего встречного ордера. «Отключить повтор» во время сопровождения завершает будущий подхват. «Стоп» доступен при безопасном состоянии. Закрытие окна оставляет супервизор в работе.

«Настройки стратегии…» показывает дистанцию SL, порог поддержки и все 24 лота по ступеням. Значения по умолчанию 0.80 и 0.40. Для изменений поставьте стратегию на паузу при пустом цикле. Пульт сохраняет изменения после подтверждения контроллером. При отсутствии связи или при незавершённом цикле ориентируйтесь на статусы в пульте и MT5.

После исполнения RECOVERY проверяет SL каждой привязанной позиции от её фактической цены входа. Максимальная дистанция защитного SL равна меньшему из двух значений — настройке «Дистанция SL» и 0,80 единицы цены. Для BUY уровень защиты находится ниже входа на эту дистанцию, для SELL — выше. Помощник сохраняет более близкий SL, уже достигнутый безубыток и текущий TP. Правило действует и для ручной позиции после подхвата, и для позиции, открытой ордером цепочки. Цена, лот и исходный SL самой заявки до исполнения рассчитываются как раньше.

Например, если BUY STOP исполнился по 2500,30, а прежний SL равен 2499,20, то при дистанции 0,80 помощник запросит SL 2499,50. Изменение вступает в силу после подтверждения брокера. Если новый уровень пока недопустим по котировке, помощник ждёт допустимую цену. Быстрое закрытие или проскальзывание при срабатывании SL могут увеличить фактическую потерю в цене.

Если брокер отклоняет перенос цены встречного STOP, смотрите подробности под текущей ступенью цикла. Прежняя цена действует, пока ордер остаётся выставленным. Если он уже исполнился, RECOVERY сверяет ордер и сделки в истории MT5. Пока идёт сверка, не выставляйте копию ордера вручную.

При сообщении «Сверка завершения цикла» RECOVERY проверяет по истории MT5 закрытие обеих позиций. После подтверждения пульт возвращается в «Готов к выбору режима» на паузе. Для следующего цикла нажмите «Старт» и выберите режим ожидания.

После выхода по SL поддержки у стратегии могут остаться два STOP — встречный и повторный в сторону закрытой позиции. Если оба полностью отменены до исполнения, RECOVERY сверяет оба тикета с историей MT5 и показаниями помощника. Когда по символу больше нет позиций и ордеров и сверка завершена, пульт показывает «Готов к выбору режима». Повторное ожидание выключается. Для следующего цикла выберите режим ожидания. Если после перезапуска пульт показывает «Python — на паузе», сначала нажмите «Старт».

Пересборка

В отдельном архиве Source находятся Python, исходники двух помощников MQL5, тесты и скрипты установщика. Скомпилируйте RecoveryPythonSL.mq5 и RecoveryPythonVerifier.mq5 в MetaEditor вместе с .mqh. В папку wheels положите оригинальные колёса PyPI cp313 win_amd64 для MetaTrader5 5.0.6231 и NumPy 2.5.5. Имена и SHA-256 заданы в installer\package_spec.py. Далее выполните из корня исходников:

py -3.13 -B installer\build_package.py --source . --helpers .\mql --wheels .\wheels --out .\dist

Чтобы при пересборке загрузить отсутствующие колёса с PyPI и проверить каждый закреплённый SHA-256, добавьте флаг --download-missing-wheels. Готовый Install.cmd работает с уже вложенными файлами.
