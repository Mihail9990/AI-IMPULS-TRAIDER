# Windows VPS: установка и проверки до торговли

Этот ZIP содержит локальную версию исходников и отдельный launcher **без кнопки запуска торговли**. Обновление GitHub, VPS deploy и live-запуск не выполнялись. Требуется Windows, Python 3.13 x64 с Tk и Python Launcher (`py`), доступ к PyPI для установки зависимостей. Это переносимый ZIP с Python launcher, не нативный EXE.

1. Сохраните ZIP и распакуйте **все** файлы в отдельную папку, например Downloads\TradFiPretrade. Не удаляйте старую установку или AppData.
2. Откройте `START_PRETRADE.cmd`. При отсутствии Python установите Python 3.13 x64 с Tk и launcher; повторите запуск.
3. Нажмите «Установить / обновить». Используются исходники именно из этого ZIP с проверкой SHA256. Зависимости устанавливаются в отдельный venv. До переключения версии автоматически выполняется полный offline backend набор; неполный набор или ошибка запрещают переключение.
4. Через кнопку локальных настроек проверьте свой `service.json`: существующий путь terminal64.exe, свой login, Bybit-Live-6, XAUUSD.s, backend mt5_direct_v1, time_profile bybit_live6_time_v1. Не отправляйте конфигурацию, токены или скриншоты с секретами. Существующие настройки не импортируются из других папок, не сбрасываются и не копируются в ZIP.
5. Выполните проверки среды, конфигурации и offline логики. Сообщения проверки очищены от значений учётных данных. Offline тесты используют временные данные, fake MT5 и запрет сетевых соединений. Проверка среды подтверждает платформу/наличие пакетов, а не готовность к торговле.
6. По желанию выполните **READ_ONLY MT5** после подтверждения. Initialize может открыть настроенный терминал. Checker не вызывает login, order_send, order_check, symbol_select и не меняет ордера, позиции или состояние стратегии. Уже работающие сторонние советники терминала этим launcher не контролируются. Проверяется подключение, соответствие счёта, Bid/Ask, позиции/pending и чтение M1. Отдельная HTTP проверка UTC выполняется только при этом явном действии. Непроверенные MT5 timestamps остаются UNVERIFIED; возраст котировки не выдумывается, execution_ready всегда false. WARN не является разрешением торговли.
7. Откройте **MOCK панель**. Это локальная HTML-страница с явно тестовыми данными, без сервера и брокерских команд. Проверяйте вкладки, масштаб, preview/Apply и подтверждения. Данные настоящего терминала в этот preview не поступают. Chromium тесты панели выполнены разработчиком; launcher на VPS запускает backend offline tests, а не устанавливает Playwright.

## Сохранность и ограничения

Корень прежний: `%LOCALAPPDATA%\AI_IMPULS_TRADFI_Manager`. Перед обновлением существующая SQLite сохраняется согласованной резервной копией в `backups\before-update-*`; проверяется integrity_check. Старые каталоги релизов сохраняются. `service.json`, `telegram.json`, журналы и другие старые файлы остаются на месте, автоматически не мигрируют. SQLite содержит историю и может содержать частные данные: резервные копии не пересылайте. RECOVERY, учёт закрытий и независимые safety latches не сбрасываются.

Существующая блокировка параллельных экземпляров сохранена. Занятый экземпляр, активное/неоднозначное или несовместимое состояние запрещают обновление. Launcher не снимает чужую блокировку, не убивает процессы и не расследует старую установку. Не удаляйте lock/SQLite вручную ради продолжения. Ошибку сообщайте текстом без секретов.

После установки и всех проверок никакой сервис автоматически не запускается. Сохранённый enable_trading не изменяется, но новый launcher его не использует для торгового запуска. Старый launcher остаётся отдельным приложением со своими возможностями: для этих проверок используйте только START_PRETRADE.cmd.

Linux проверки не подтверждают исполнение Windows GUI, msvcrt, pip wheel installation или реального MT5. Эти шаги на VPS ещё не выполнены. Ни проверка среды, ни PASS offline тестов не отменяют MT5_TIMESTAMP_SEMANTICS_UNVERIFIED и другие ограничения торговли.
