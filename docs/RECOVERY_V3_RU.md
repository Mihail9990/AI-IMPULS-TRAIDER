# RECOVERY V3: локальная реализация

V3 — единственная основная логика панели и новых циклов. Выбора версий нет.
Форма «Закрыть позиции и выбрать диапазон» удалена вместе с её обработчиком.
Начальный вход, стоп новых входов, ручная сверка, SL на вход, обратная лестница,
настройки TP, списание остатка, график и логи сохранены.
Устаревшие параметры диапазона и объёма RECOVERY не редактируются в панели;
при сохранении общих настроек их значения передаются без изменения для
совместимости со схемой сервера. Объём каждой новой ступени задаёт выбранный профиль; см. [профили RECOVERY](RECOVERY_PROFILES_RU.md).

Открытый старый цикл не превращается в V3 автоматически: сервер блокирует
миграцию до сверки. Панель показывает причину блокировки и не отправляет
V3-команды для старого режима. Брокерские позиции не закрываются этим обновлением.

Начальный вход по M1 и его одноразовая отмена сохраняются. После SL V3 не строит
автоматический диапазон: ждёт команды панели. Входы состоят из 1–20 отдельных
частей с точными объёмами и TP выбранного сохранённого профиля. MARKET доступен
сразу по выбранной стороне либо после закрытия текущей/следующей свечи; STOP
доступен после текущей/следующей свечи. Направление свечи определяется Close/Open,
отступ STOP считается от Close и хранится отдельно. Doji отменяет этот вход.
Пропущенные свечи не воспроизводятся; перезапуск отменяет запланированный вход.
Пересечённый STOP не превращается в MARKET.

Связанные встречные STOP выставляются на SL первой части. Пока первая часть
открыта, изменение SL проходит сверку отмены и замены связанных STOP. После TP1
связанные STOP остаются на последнем уровне. Если остальные исходные части
закрылись SL, эти STOP продолжают ждать. При TP всех исходных частей pending
отменяются. Исполненные встречные части могут сопровождаться одновременно со
старыми остатками; их TP/SL и история не смешиваются. При двух активных группах
кнопки SL и новой привязки отключены. Команда отмены удаляет лишь неисполненные
остатки; неизвестные результаты не повторяются вслепую.

Для новых профилей TP считается от фактического входа каждой ступени на её заданное расстояние, без увеличения ради долга. Старые группы без снимка профиля сохраняют прежний расчёт по входам и подтверждённому долгу. Для профиля каждая подтверждённая полностью исполненная ступень получает свой точный TP, даже если другие STOP ещё ожидают или история исходного SL задержалась. Изменения проходят существующую сверку команд. Только прежние группы без снимка ожидают подтверждённого исходного выхода для расчёта долга. TP1 переносит SL оставшихся частей на их собственные входы.
Управление ждёт закрытия всех активных групп; при остаточном долге снова ждёт
ручного входа, при погашенном долге возвращается к M1.

Новая панель SL меняет расстояние шагом 0.10 после подтверждения. Каждая часть
считается от собственного входа. Раздвижение не обходится округлением tick или
ограничениями stops/freeze. Свёрнутость двух панелей хранится независимо.

Проверки выполняются только локально, с искусственными брокерскими API в тестах. Реальные сделки,
развёртывание и публикация не выполнялись. Браузерная геометрия не подтверждена:
Chromium не запускается в этой среде из-за запрета socket(); Node DOM-тесты
проверяют действия, состояния и защитные условия, а не фактический layout.

Если исполнилась только одна часть профиля, расстояние TP её исходной ступени не увеличивается ради
погашения всего долга. После закрытия остаток RECOVERY ожидает следующего входа.
Прежние кнопки переноса SL на вход и обратной SL-лестницы учитывают известные
связанные pending; при незавершённой сверке или двух активных группах блокируются.
Выбор профиля, его редактирование и настройка SL новых корзин не снимают и не меняют уже выставленные V3 STOP. Правка параметров начального входа сохраняет ожидающие профильные корзины. Прежние группы без снимка при правке общих настроек используют прежний механизм отмены и замены. При привязке к SL подтверждённая правка исходного SL по-прежнему меняет уровень связанных STOP, сохраняя зафиксированные ступени, объёмы, TP и SL самой встречной корзины. Пересечённый уровень не исполняется MARKET: требуется ручная сверка.
