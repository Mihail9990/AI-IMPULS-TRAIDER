# Установка основного LIVE-бота на Windows

Нужны Windows x64, Python 3.13 x64 с Tcl/Tk и установленный MetaTrader 5. Установщик не включает торговлю, не вводит пароли MT5 и не запускает сервис автоматически.

1. Скачайте полный опубликованный ZIP отдельной LIVE-версии и распакуйте его.
2. Запустите `START_LIVE.bat` (или `START_INSTALLER.bat`). Приложение устанавливается в `%LOCALAPPDATA%\AI_IMPULS_LIVE`.
3. Нажмите «Установить / обновить», затем «Настройки». Заполните локальный `data\service.json`. Не публикуйте его содержимое.
4. Проверьте счёт, сервер, символ, профиль времени и пароль панели. Сначала используйте READ_ONLY, панель `http://127.0.0.1:8765`.
5. Реальный запуск остаётся отдельным явно подтверждаемым действием и требует всех прежних защитных флагов. Остановка процесса не закрывает позиции и не отменяет ордера.

## Обновление с прежней независимой LIVE-установки

Старый установщик ожидает прежний общий контракт и не примет новый отдельный LIVE-архив. Остановите работающий процесс и запускайте `START_LIVE.bat` **из нового полного ZIP**, а не старый launcher. Новый bootstrap использует прежний каталог `AI_IMPULS_LIVE` и сохраняет его настройки, базу, историю, RECOVERY и логи. Не удаляйте папку `data`, не создавайте пустую базу вместо существующей и не копируйте файлы SQLite вручную.

Новый формат релиза: `independent-install-contract.json`, format 2, roles `["live"]`. Несовместимые архивы отвергаются до переключения версии. Rollback меняет только код и допускается лишь на совместимую отдельную LIVE-версию. Возврат на прежний общий релиз заблокирован; данные не откатываются.

Если обнаружена старая общая установка `AI_IMPULS_TRADFI_Manager`, автоматический перенос отключён. Сохраните её целиком и сначала выполните отдельную проверку переноса LIVE и его обязательств. Установщик не присваивает неизвестные каталоги и не сбрасывает потерянные конфигурации/базы.

## Защита данных

Обновление и rollback требуют остановленного LIVE-процесса, доступных блокировок состояния и счёта и совместимого неактивного сохранённого состояния. Перед переключением создаётся согласованная SQLite-копия. Настройки и секреты не включаются в backup. Если проверка или подготовка зависимостей не прошла, действующий указатель версии сохраняется.

HTTPS настраивается отдельно через `SETUP_PHONE_HTTPS.bat` после проверки локальной панели. Изменения системы и публикацию панели подтверждайте в мастере. Работа инсталлятора на Windows и доступ с телефона требуют проверки на целевом сервере; Linux offline-тесты этого не заменяют.
