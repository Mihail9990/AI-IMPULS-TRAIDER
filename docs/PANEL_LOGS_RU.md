# Логи панели

Внизу «Параметры» сохранены просмотр страницами и скачивание UTF-8 `.txt`:
live — торговый контур, paper — симулятор, runtime — очищенный общий файл сервиса.
Требуется авторизация; путь файла нельзя передать через URL.
Показываются контекстные изменения состояния/параметров, фаза, долг, уровни/объёмы,
безопасные поля запросов и результатов, IDs операций/receipts и доступные коды ошибок.
Снимки содержат версию схемы, базовый commit, время UTC и отдельно отображение UTC+2.
Старый audit без timestamp не датируется задним числом. Тики постоянно не записываются.

Проекция исключает пароли, токены, заголовки, полные account IDs и сырые сообщения.
Экспорт ограничен 1 MiB, страница — 16000 символов; manifest указывает ограничения.
Контекстные файлы ротируются: 5 MB и 3 предыдущих сегмента на контур.
Выгрузка читает ограниченные хвосты; возможно повторение текущих снимков.
Существующие live/paper файлы схемы demo-diagnostics-v1 остаются читаемыми.
Кнопок удаления/очистки нет; старые базы и файлы автоматически не удаляются.

## Удалённая функция DEMO

Удалены отдельный DEMO MT5 сервис, его кнопки, маршруты и шаблон конфигурации.
Старый запуск с `--demo-service` завершается ошибкой аргументов ДО чтения конфигурации
и подключения к MT5. Старые `/api/demo/*` запросы не попадают в торговую очередь.
Основная стратегия, read-only диагностика времени и бумажный симулятор не изменены.

Если старая версия DEMO когда-либо запускалась, её процесс, счета, ордера и базы
эта поставка не трогает. Обновление исходников не останавливает уже запущенный процесс.
Сохраните прежние данные/архив для сверки; не заменяйте ими рабочую торговую базу.
Новый набор не даёт автоматического разрешения на реальную торговлю.
