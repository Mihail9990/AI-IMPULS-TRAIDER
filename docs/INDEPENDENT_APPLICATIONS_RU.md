# Независимая установка LIVE

Основной бот устанавливается в `%LOCALAPPDATA%\AI_IMPULS_LIVE`. Внутри находятся собственные `releases/<sha>/code`, `venv`, `current.json`, `data/service.json`, `data/state.sqlite3`, журналы и резервные копии. Код не импортируется из соседнего репозитория или установленного приложения. Пути изменяемых данных ограничены собственной папкой `data`.

`START_LIVE.bat` и `START_INSTALLER.bat` открывают одно окно управления LIVE. Обновление, rollback и запуск сериализованы блокировками приложения, состояния и счёта. Обычный запуск — READ_ONLY. Исполнение требует отдельного подтверждения и всех защитных настроек. Обновление не запускает сервис автоматически.

Полная инструкция новой установки, безопасного обновления существующей LIVE-установки из нового ZIP и ограничений rollback: [Windows установщик](WINDOWS_INSTALLER_RU.md).

Старую общую установку нельзя автоматически преобразовать этим выпуском. Не удаляйте её данные или SQLite для обхода проверки. Сначала нужны сохранение исходных данных и отдельная проверка LIVE-обязательств. Остановка программы не закрывает позиции брокера.
