# DEMO XAUUSDT: отдельная функциональная проверка

Эта версия добавляет тестовые кнопки на главный экран и «Логи» внизу настроек.
Стратегия XAUUSD.s и бумажный симулятор не меняют символ или расчёты.
Проверки выполняются только по отдельным подтверждённым шагам, без автоматического цикла.

## Подключение на VPS позднее

В этой поставке никто не подключался к MT5 и не отправлял даже демо-заявки.
В терминале пользователь самостоятельно выбирает свой Bybit DEMO-счёт.
Не отправляйте пароль в чат и не записывайте его в конфигурацию.
Наличие именно XAUUSDT и доступность нужного типа счёта заранее не подтверждены:
код читает фактическую спецификацию, не подставляет CFD или другое имя инструмента.

Для отдельного терминала без XAUUSD.s скопируйте `tradfi_demo.example.json` в локальный
конфиг, заполните путь terminal64.exe, ожидаемые login/server из терминала. Это
привязка идентичности, а не команда переключения счёта. Укажите отдельную базу.
В окружении должен быть ранее установленный сильный `TRADFI_WEB_PASSWORD` (≥32 символа).
Запуск: `python tradfi_main.py --mode mt5 --demo-service --config tradfi_demo.json`.
Этот режим не загружает основную торговую базу, стратегию или бумажный симулятор.
Он открывает ту же панель с секцией DEMO; остальные торговые действия недоступны.
В обычном сервисе секция DEMO тоже доступна, но только для уже привязанного счёта
и после доказанной остановки/пустого состояния основного контура.
Для другого демо-счёта используйте отдельный терминал/конфиг/базу, не меняйте рабочую базу.

По умолчанию слушается только 127.0.0.1. Для Android потребуются отдельно настроенные
HTTPS и доступ к VPS; эта поставка их не устанавливает. Прямой публичный HTTP не включается.

## Один шаг за подтверждение

При старте, обнаруженном разрыве связи или смене счёта переключатель OFF.
Включение не отправляет заявку. После него доступны:

- BUY / SELL минимальным фактическим объёмом;
- изменение SL/TP своего билета и отдельное подтверждённое закрытие;
- BUY STOP / SELL STOP, изменение цены/защиты и отмена своего STOP;
- read-only сверка неопределённой операции.

Вводятся абсолютные цены: SL/TP обязательны, для рыночного входа поле STOP=0.
Шаг цены, объём, stops/freeze, поддержка market/STOP/SL/TP/GTC и FOK проверяются.
Цены не округляются, пересечённый STOP не превращается в рыночную заявку.
Используются Bid/Ask по направлению; при изменении котировки во время проверки шаг отклоняется.
В панели видны фактические contract/tick/volume/filling параметры, свежесть и оценка маржи.
Комиссия и спред не предполагаются по CFD; фактический спред виден по Bid/Ask.
До ответа брокера открытость торговой сессии не гарантируется одним свежим тиком.

Эта первая диагностика требует **hedging** и FOK для рыночных тестов. Для netting/exchange
показывается причина отказа; независимость билетов не предполагается. Наличие XAUUSDT
с такими свойствами на конкретном Bybit DEMO надо проверить в терминале.
Посторонние позиции/ордера XAUUSDT блокируют тест, никогда не закрываются.
Допускается один собственный билет или один STOP, затем его завершение.

Перед каждой мутацией заново читается `account_info.trade_mode` и сравнивается с
`ACCOUNT_TRADE_MODE_DEMO`, а также точные login/server и разрешения API.
Название сервера и переключатель не доказывают DEMO. После order_check проверка повторяется.
MT5 Python не предоставляет атомарную привязку order_send к login: переключение счёта
внутри уже выполняющегося native-вызова нельзя исключить программной пред-проверкой.
Поэтому терминал для диагностики должен оставаться отдельным DEMO-терминалом.

OFF немедленно запрещает новые шаги очереди, но не отменяет уже отправленный native-вызов.
OFF **сохраняет** открытые билеты, STOP, SL/TP. Остатки показываются; для закрытия/отмены
нужно включить тест снова и подтвердить конкретную операцию. Общей массовой очистки нет.
Основная стратегия блокируется, пока тест включён, есть его остатки или неопределённость.

## UNKNOWN / перезапуск

Уникальные operation/receipt IDs и намерение сохраняются ДО отправки в отдельном SQLite.
Повтор того же запроса возвращает результат, не отправляет заявку повторно.
Потерянный ответ и неподтверждённое состояние после ACK приводят к UNKNOWN/OFF.
«Сверить UNKNOWN» ищет положительные доказательства в собственных позициях/ордерах и истории.
Отсутствие записи само по себе не разрешает повтор. Если доказательств нет, требуется
сверка в терминале; автоматического сброса неопределённости нет. Защита сохраняется.
После перезапуска контекст страницы меняется. Старое локальное ожидание снимается отдельной
кнопкой только после серверной сверки и отсутствия UNKNOWN; запрос не повторяется.

## Логи

«Параметры → Логи»: live, paper, demo, очищенный общий runtime-файл; просмотр страницами
и скачивание UTF-8 `.txt`, включая Android Chrome. Требуется авторизация, Origin и служебный заголовок.
Путь файла нельзя передать через URL. Логи не очищаются кнопками панели.

Записываются версия схемы/базовый commit, scope, наблюдаемое UTC и отдельно UTC+2,
изменения состояния/параметров, фаза, долг, реальные уровни/объёмы, запросы и ответы
с безопасными числовыми полями, Bid/Ask контекста, спецификация, DEMO-доказательство с
маскированным номером, operation/run/receipt IDs, retcode, UNKNOWN и сверка.
Для исключений order_send сохраняются тип и кадры traceback (имя файла/функция/строка),
без текста исключения, исходных строк, локальных переменных и абсолютных путей.
Полные счета, пароли, токены, headers и сырые комментарии MT5 исключены.
Свободный текст фильтруется, неподдерживаемые поля опускаются; это указано в manifest.
Старый audit не имеет timestamps: ему не придумывается время задним числом.
Изменения settings видны как последовательные снимки, не как полный исходный конфиг.

Контекстные JSONL-файлы новых логов: до 5 MB + 3 ротации на scope; текущие snapshots
ограничены 100, audit 200, demo events 500. Тики постоянно не записываются:
котировка сопровождает изменение состояния/решение. Экспорт ≤1 MiB, страницы 16000 символов,
архивные хвосты максимум 4×128 KiB; manifest обозначает ограничения и возможные повторы.
Старая версия log-файла экспортируется существующим очищающим фильтром.
Частичная ошибка диагностического файла не должна разрешать торговлю или менять её параметры.
