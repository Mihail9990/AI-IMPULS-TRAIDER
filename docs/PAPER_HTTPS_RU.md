# HTTPS для PAPER с телефона (отдельный мастер)

Запустите двойным щелчком `SETUP_PAPER_PHONE_HTTPS.bat` из папки кода.
Windows запросит UAC; используйте того же пользователя Windows, который устанавливал PAPER.
Python 3.13 с Tkinter должен быть установлен. Ручные команды PowerShell не нужны.
Старый `SETUP_PHONE_HTTPS.bat` и его LIVE-мастер не изменены.

1. Остановите только PAPER штатной кнопкой его установщика. LIVE не останавливайте.
2. В новом окне проверьте независимую папку PAPER, публичный IP или домен VPS.
3. Сохраните показанный новый пароль PAPER (не менее32 символов) в безопасном месте.
   Он заменяет только пароль PAPER при подтверждении сохранения настроек. Пароль не выводится в диагностику/журнал.
4. Нажмите «Установить PAPER HTTPS». Официальный Caddy2.11.7 скачивается автоматически по HTTPS и проверяется по закреплённой SHA256.
   Если загрузка недоступна, скачайте официальный архив на VPS обычным браузером и выберите его кнопкой ZIP.
5. Подтверждайте каждое действие непосредственно перед его выполнением: настройки PAPER, создание собственной службы,
   правило Windows Firewall, автозапуск при загрузке Windows и запуск службы.
   Служба первоначально создаётся в ручном режиме; автозапуск разрешается только отдельным подтверждением с условиями CA. Отказ останавливает последовательность, уже выполненные действия остаются в журнале.
6. Запустите PAPER его обычным установщиком. Нажмите «Проверить сертификат».
7. Откройте HTTPS-адрес на телефоне через мобильную сеть и войдите паролем PAPER.

## Границы и безопасность

- Только завершённая независимая установка с ролью PAPER, backend `paper_mt5_quotes_v1`, без реальных сделок.
- Собственная папка `paper-https`, служба `AIImpulsPaperHTTPS`, отдельные сертификаты и защищённая резервная копия.
- Backend всегда `127.0.0.1:8766`. Мастер не публикует8766, не меняет LIVE и не запускает торговлю.
- По умолчанию только входящий TCP443, правило ограничено исполняемым файлом собственного Caddy.
  HTTP/3 отключён: используются только HTTP/1.1 и HTTP/2. UDP443 не открывается. HTTP-redirect и административный API Caddy отключены.
- TCP80 включается только при явно выбранном ACME HTTP challenge и отдельном подтверждении правила.
  Обычно сертификат получается через TLS-ALPN на443.
- IP/домен передаётся Let's Encrypt для выпуска/автопродления публичного сертификата с Certificate Transparency.
  Перед запуском показана ссылка на условия: https://letsencrypt.org/repository/.
- Если уже есть LIVE, неизвестная HTTPS-служба, собственная незавершённая установка либо занят80/443,
  мастер отказывает и ничего чужого не останавливает. Для совместного доступа нужны отдельный VPS/IP либо отдельно спроектированный reverse proxy.
- Домен должен указывать на VPS. Windows Firewall и firewall облачного провайдера различаются:
  этот мастер не меняет облачный firewall/NAT/DNS. В панели провайдера может потребоваться разрешить443.
- Установка службы не означает готовность телефона. Проверка отдельно проверяет доверенный TLS-сертификат,
  точный HTTPS-адрес без перенаправлений, уникальный идентификатор собственного proxy, страницу PAPER и локальные привязки службы/панели.
  Она не проверяет пароль, внешний маршрут с телефона или гарантированное продление сертификата.
- Проверку сертификата нельзя отключить; self-signed сертификат не принимается.

## Ошибка, диагностика и откат

Кнопка «Диагностика» показывает статус транзакции, ожидающее действие, имена служб и порты без паролей.
Повторное применение незавершённой установки запрещено. При известном исходе используйте «Откат PAPER HTTPS»:
отдельно подтверждаются отключение автозапуска, остановка/удаление только собственной службы, удаление только собственного неизменённого
правила firewall и восстановление своей конфигурации. Изменённые файлы/правила/службы не присваиваются.

После отказа до изменений или успешного отката «Архивировать проверенную подготовку» сохраняет каталог попытки
под новым именем без удаления резервных копий и позволяет заново подготовить план.
Если Windows-команда завершилась тайм-аутом или процесс прерван во время команды, исход неизвестен:
автоматическое повторение, откат и архивация блокируются до отдельной сверки специалистом.
Если запись самого журнала/identity не удалась, каталог не присваивается автоматически; нужна ручная проверка специалистом.

Проверки в репозитории работают с подставным Windows-адаптером без реальных служб/firewall/сети.
Windows UAC, PowerShell и реальная выдача сертификата должны быть проверены отдельно на тестовом Windows/VPS;
успешные локальные тесты не означают, что HTTPS уже развёрнут.
