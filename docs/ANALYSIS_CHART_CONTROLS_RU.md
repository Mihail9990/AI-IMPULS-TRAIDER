# Управление аналитическими графиками

Вкладка «Анализ» открывает график фигур на всю доступную высоту. Стрелка в заголовке сворачивает его; разворачивание другого графика автоматически сворачивает первый. Оба заголовка остаются доступны.

- M1 / M15 / M30 / H1: независимый таймфрейм каждой карточки.
- «Оценка»: 50, 100, 200 или 300 закрытых свечей для отдельного перерасчёта. Это не просто обрезка картинки. Пересчёт выполняется только в изолированном аналитическом процессе; обновление может занять несколько опросов.
- «+» / «−», колесо или жест двумя пальцами: масштаб. Перемещение одним пальцем/мышью: история по горизонтали, диапазон цен по вертикали. Shift + колесо меняет вертикальный масштаб. «К цене» возвращает последние свечи и автоматический диапазон.
- Bid/Ask обновляются из того же потока MT5, что основной график. Аналитические свечи остаются закрытыми, живая цена не превращается в выдуманную свечу или признак.
- Названия паттернов/фигур убраны с полотна, но доступны в «Сведения». Маркеры и геометрия сохраняются.
- Зелёная пунктирная стрелка показывает только условное направление, не прогнозную цену или гарантированную цель. Длина стрелки условная экранная. Для свечей требуется однозначный признак на последней закрытой свече; для фигур поддержан первый подтверждённый закрытием пробой шеи двойной вершины/дна. Нейтральные, конфликтные и неподтверждённые случаи не получают стрелки. При потере/смене источника стрелка скрывается.

Управление графиками не отправляет торговые команды и не меняет параметры стратегии.
