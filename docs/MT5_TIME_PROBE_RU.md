# Read-only проверка времени MT5

Отдельный `tools/mt5_time_probe.py` не зависит от файлов проекта. Нужен установленный
официальный пакет `MetaTrader5`, уже открытый и авторизованный терминал
`C:/Program Files/MetaTrader 5/terminal64.exe`, видимый `XAUUSD.s`.
Оставить Algo Trading OFF. Если открыт Python (`>>>`), сначала выполнить `exit()`.

Сохранить файл в отдельную доступную для записи папку, открыть её в Windows cmd:

```bat
py mt5_time_probe.py
```

Скрипт делает 10 измерений за 90 секунд, печатает прогресс и создаёт рядом новый
`mt5_time_report_<UTC-время>.txt`. API-вызовы и чтение истории могут увеличить время
работы; команда не является строгим 90-секундным таймером. Отправить текстовый отчёт.
Предыдущие отчёты не перезаписываются. Ctrl+C завершает проверку с отключением Python
API; терминал остаётся открыт. Если initialize не удался, измерения не выполняются.

Отчёт содержит UTC часов ПК, исходные времена тиков, возраст без коррекции, времена
текущей и двух предыдущих доступных M1 свечей, продвижение времён. Возраст отрицательный,
если метка тика впереди часов ПК. Сдвиг не определяется автоматически и не применяется.

История запрашивается от `now−24h` до `now+60s` и до `now+3h+60s` с одинаковым началом.
Выводятся только количества, крайние времена и результат сравнения существующего
события с запросом по ticket (идентификатор используется только внутри программы).
Последовательные запросы не атомарны: разница количеств сама по себе не доказывает
часовой пояс. Пустая история — `EMPTY_INCONCLUSIVE`, ошибка/None — отдельный статус.
Даже непустой ответ не доказывает полноту истории. Новые сделки ради проверки не нужны.

Скрипт не читает данные счёта, не выводит tickets, баланс, PnL, комментарии и исходные
сообщения ошибок. Он не вызывает торговые методы, не меняет часы/разрешения, не читает
и не изменяет конфиги, SQLite или mailbox. Единственная запись — новый текстовый отчёт.

Offline-проверка без нативного MT5:

```bash
python -m unittest discover -s tests -p test_mt5_time_probe.py -v
```
