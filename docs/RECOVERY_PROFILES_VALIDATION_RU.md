# Проверка профилей RECOVERY

Локальная реализация проверена 10 ноября 2026 года отдельно в LIVE и Simylator. Публикация, развёртывание и реальные сделки не выполнялись.

## Выполнено

- Python 3.13, полный офлайн-набор LIVE: 1016 тестов, успешно.
- Python 3.13, полный офлайн-набор Simylator: 469 тестов, успешно.
- В обоих запусках запрещено сетевое подключение; попыток реальной сети: 0.
- 28 профильных тестов в каждом приложении: точные разные объёмы/TP, остаток долга, неизменность снимков, перезапуск, отложенные свечи, связанные STOP, последовательные и частичные исполнения, сохранение исходных индексов, неизвестный MODIFY и broker min/step/tick.
- Node: V3-обработчики, уведомления активности и высота графика — успешно в обоих приложениях. Проверены подтверждения, отмена, устаревшие формы, точные десятичные значения, SL после переноса на вход и SL с дополнительными знаками после запятой.
- Статическая структура панели, синтаксис Python/JS и проверка пробелов diff — успешно.

## Ограничения проверки

- Chromium не запускается на проверочной машине из-за запрета socket(); фактическая геометрия мобильного/настольного интерфейса не подтверждена. Сценарии браузерной проверки подготовлены.
- Установка на реальном Windows-сервере и взаимодействие с реальным MT5 не выполнялись.
- У каждого приложения остаётся собственный установщик и запуск. Установщик получает опубликованный код из своего GitHub-репозитория. Непубликованный исходный ZIP сам по себе не означает, что «Установить / обновить» установит эти новые изменения.
