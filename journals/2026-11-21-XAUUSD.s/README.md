## Как сопоставлять записи

Один код `O…` обозначает один и тот же исходный тикет во всех таблицах. Позицию можно связать с открывшим её ордером и обеими сделками. Коды `D…` обозначают сделки. Номера действуют внутри этой выгрузки. Время события у брокера и время записи сообщения терминалом могут различаться на несколько миллисекунд. Для измерения задержек используйте метки одного источника.

В журнале Python `action_seq` передаёт порядок действий, а `confirmation_seq` — порядок записи подтверждений закрытия. Числовой код и время ответа заполнены там, где сохранилась квитанция. Поле причины ордера в MT5 описывает его создание. Автор последующей отмены устанавливается отдельно, например по совпадающей команде удаления в Python.
