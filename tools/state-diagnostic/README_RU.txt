Диагностика сохранённого состояния — только чтение

1. Полностью распакуйте ZIP в отдельную папку. Не заменяйте файлы установки.
2. Закройте окно установщика. Не удаляйте базу/lock и не завершайте неизвестные процессы ради диагностики.
3. Дважды нажмите START_STATE_DIAG.cmd. Нужен Python 3.13 с Python Launcher (как у нового установщика). Если его нет, появится PYTHON_3_13_LAUNCHER_REQUIRED; данные не меняются.
4. Пришлите текст или фото только JSON. Окно ждёт нажатия клавиши. Отчёт не сохраняется автоматически в файл.

Читаются current.json и service.json в %LOCALAPPDATA%\AI_IMPULS_TRADFI_Manager; из service.json используется только путь state_file. SQLite открывается mode=ro с query_only. Обрабатывается актуальное состояние WAL, immutable не используется. Скрипт не создаёт/снимает application locks, не запускает MT5, проект, сеть или торговлю и не выполняет SQL изменений. SQLite может использовать собственную координацию чтения WAL; это не обход блокировки установщика.

Вывод: commit установленного кода, наличие checker, флаги совместимости, наличие цикла, безопасная категория phase, количества незавершённых/несопоставленных команд, совпадение учёта сделок. Нет login, путей, токенов, ticket/command ID или сырого текста исключений. READ_COMPLETE означает только успешное чтение; не отсутствие причин блокировки и не разрешение торговли. LIVE-состояние счёта не проверяется. READ_FAILED/error_stage указывает этап ошибки без раскрытия данных.

На Linux/Python 3.12.14 пройдены 17 тестов временных фикстур, включая приватность, отсутствие SQL изменений, повторный запуск, отсутствующую/повреждённую базу, активный цикл, UNKNOWN, несовместимость, journal/ledger и WAL. Windows CMD/GUI и реальный VPS здесь не запускались. Скрипт не исправляет состояние и не разрешает обновление.

Версия отчёта STATE_READ_ONLY_V2:
phase: IDLE, WAIT_CANDLE, NEXT_PAIR, PAIR, POSITION, COOLDOWN, PAUSED, PAUSED_CYCLE, SAFE_PAUSE, MANUAL, WAIT_START, WAIT_TRIGGER. Иные значения не раскрываются: MISSING (нет поля), NULL, INVALID_TYPE, UNKNOWN_STRING.
cycle_kind и time_block_kind: MISSING, NULL, EMPTY_OBJECT, OBJECT, INVALID_TYPE. Содержимое объектов и причины блокировок не выводятся. cycle_present сохраняет прежнее значение bool(cycle); оно само по себе не подтверждает корректность структуры.
stop: TRUE/FALSE только для настоящего JSON boolean; иначе MISSING или INVALID_TYPE.
phase_allowed_by_installer: только соответствие фазы списку IDLE/PAUSED/WAIT_START, не результат всех проверок установщика и не разрешение обновления или торговли. SAFE_PAUSE и time_block не снимаются. Наличие/отсутствие объектов не объясняет их причину и не подтверждает состояние MT5.
Новая версия проверена только на временных Linux-фикстурах. CMD сохранён без изменений; реальная Windows-проверка новой версии не выполнялась.
