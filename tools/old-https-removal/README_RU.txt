УДАЛЕНИЕ СТАРОЙ HTTPS СЛУЖБЫ АНАЛИЗАТОРА

1. Извлеките все файлы в одну папку.
2. Windows: запустите REMOVE_OLD_ANALYZER_HTTPS.bat от имени администратора.
   Нужен уже установленный Python 3.13 с Tk. Пароль бота не требуется.
3. Нажмите «Диагностика». Пока ничего не изменяется.
4. Проверьте имя службы и путь XAUUSDs_Strategy_Analyzer\https_ip.
5. «Удалить старую службу» запросит отдельное подтверждение.

До остановки сохраняется локальная резервная копия. Программа НЕ удаляет
папки, сертификаты, ключи, MT5, firewall или новую службу AIImpulsHTTPS.
Неизвестный владелец/обёртка NSSM/WinSW/чужой порт — отказ без удаления.
Поддерживается прямой caddy.exe run --config с абсолютными путями exe и
Caddyfile в одной папке анализатора, LocalSystem, без зависимостей.
Номер PID или имя caddy сами по себе не являются разрешением удаления.

Восстановление: «Восстановить» → выбрать backup-... в
%LOCALAPPDATA%\AIImpuls_OldHTTPS_Backups.
Не удаляйте оригинальную папку анализатора: она нужна для восстановления.
Копии могут содержать секреты старой конфигурации. Не отправляйте их в чат.
При частичном отказе проверьте диагностику/резервную копию; не запускайте
повторно несколько утилит. Если другой процесс занял порт после удаления,
он не будет остановлен.

Проверено offline на имитации служб. На реальном VPS утилита ещё не запускалась.
Открытие окна не запускает торговлю и не изменяет службы.
