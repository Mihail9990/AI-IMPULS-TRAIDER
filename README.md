# FULL TRAIDE

RECOVERY для MetaTrader 5 с локальным пультом на Windows VPS. Python ведёт торговую цепочку. Один советник MT5 сообщает о позициях, ордерах и истории. Второй переносит стоп-лосс к цене входа при достижении заданного порога и подтверждает перенос.

## Установка на новый VPS

1. Откройте [пошаговую инструкцию на русском](INSTALL_VPS_RU.md). Она охватывает установку Python и MT5, подключение двух советников и первый запуск.
2. Скачайте [установщик для Windows x64](dist/RECOVERY-Python-Windows-1693752a53da9477.zip?raw=1) и [контрольные суммы SHA-256](dist/RECOVERY-Python-1693752a53da9477-SHA256.txt). Распакуйте установщик целиком.
3. После установки откройте «RECOVERY — Пульт управления» на рабочем столе. Кнопка «Старт» запускает обработку. Режим входа выбирается отдельно.

В режиме «Ждать рыночную позицию» Python сопровождает вашу ручную позицию. После полного ручного закрытия он отменяет оставшийся встречный STOP этой цепочки. Когда MT5 подтвердит отмену, Python возвращается к ожиданию следующей ручной позиции, если повтор включён. Если STOP успел исполниться, Python сверяет результат и продолжает сопровождение.

## Состав сборки

При торговом событии в MT5 помощник уведомляет локальный процесс Python. Контроллер перечитывает состояние ордеров и позиций, а также сверяет их периодически. У торгового процесса RECOVERY обычный приоритет Windows. Окно пульта и служба, которая записывает состояние и квитанции команд, работают в двух отдельных процессах с пониженным приоритетом. Денежный результат смотрите в истории счёта MT5. Пульт показывает ход торговой цепочки без расчёта прибыли и убытка.

Сборка `1693752a53da9477` содержит готовые советники `RecoveryPythonVerifier.ex5` и `RecoveryPythonSL.ex5`, локальный пульт и библиотеки MetaTrader5 и NumPy для Python 3.13 x64. Настройки счёта и пресеты для графиков установщик создаёт на новом VPS. Значения по умолчанию для XAUUSD.s — начальная дистанция SL 0,80 и порог переноса к цене входа 0,40 в единицах цены.
