# AI Impuls — TradFi / MetaTrader 5

Торговый бот для `XAUUSD.s`, счёта UST hedging и прямого MT5 Python API.
Точка входа: `tradfi_main.py`. Управление — адаптивная веб-панель, работающая на телефоне.
Сервис на VPS продолжает работать, когда браузер закрыт. Telegram удалён из исполнения.

## Начальный вход AUTO

После Старт ожидается закрытие текущей M1. `Close > Open` задаёт BUY STOP по
`Close + INITIAL_ENTRY_DISTANCE`, `Close < Open` — SELL STOP по `Close - INITIAL_ENTRY_DISTANCE`.
По умолчанию новой установки: расстояние **1.00**, SL **3.00**, TP **0.25** в единицах цены.
Это не число минимальных тиков брокера. Некратные тику или недопустимые уровни не округляются скрыто.

Одинаковое направление следующих закрытых свечей сохраняет точный ожидающий ордер.
Противоположное направление отменяет его и, только после подтверждённой отмены и отсутствия
исполнения, создаёт новый STOP от нового Close. Doji (`Close == Open`) ничего не меняет.
Исполнение всегда имеет приоритет, в том числе во время отмены; позиция ждёт SL/TP.
UNKNOWN, отсутствие истории или противоречивые данные не разрешают повторный вход.
Пересечённый/слишком близкий начальный уровень не заменяется MARKET: ожидается новая M1.

После завершения цикла по TP бот ждёт новую закрытую свечу. `CYCLE_COOLDOWN_SECONDS`
задаёт дополнительную паузу; для новой установки — 0, сохранённое значение не перезаписывается.
При ненулевой паузе после её окончания ожидается следующее закрытие M1.
После SL работает новая корзина независимых билетов. Старые legacy/fixed и SEMI
не доступны в штатном сервисе. [Текущая стратегия v2, миграция и незавершённые ручные режимы](docs/RECOVERY_V2_PENDING_RU.md).

## Фиксированное время MT5

LIVE и PAPER используют явный `market_time_offset_seconds`: UTC = raw MT5 − offset.
По умолчанию 0. Значение 7200 задаётся только после read-only подтверждения свежими
тиками и свечами текущего сервера; сезонных переключений и автоподбора нет.
Независимый UTC, свежесть tick/M1 и все торговые блокировки сохраняются.
Профиль привязан к базе: изменение существующего профиля или назначение ненулевого
смещения старой базе блокируется без переинтерпретации состояния.
[Настройка и ограничения](docs/FIXED_MT5_TIME_RU.md).

Read-only диагностика, без ордеров, SQLite и изменения часов:

```text
python tools/check_mt5_utc.py --config service.json
```

Результат `UTC_VERIFIED` подтверждает только текущие tick/M1, не готовность всех
торговых настроек. [Подробнее о времени](docs/BASKET_RECOVERY_RU.md#время-на-2-ноября-2026).

## График и симулятор

Основной бот и симулятор запускаются отдельными процессами с отдельными настройками.
Теперь они устанавливаются также в **разные папки с собственными копиями кода**:
`%LOCALAPPDATA%\AI_IMPULS_LIVE` и `%LOCALAPPDATA%\AI_IMPULS_PAPER`.
Используйте `START_LIVE.bat` и `START_PAPER.bat`. У каждого свои обновление,
rollback, окружение Python, конфигурация, SQLite и журналы. Для существующей
общей установки предусмотрен [проверяемый перенос без сброса данных](docs/INDEPENDENT_APPLICATIONS_RU.md).
Панели по умолчанию: http://127.0.0.1:8765 и http://127.0.0.1:8766.
У каждой свой вход и cookie; переключателя контуров внутри панели нет.
Симулятор использует read-only котировки MT5 `XAUUSD.s`, отдельную SQLite и тот же
контроллер корзины, без методов отправки ордеров в MT5. При отсутствии свежих
данных ждёт; после перерыва требует подтверждения без восстановления пропущенных
исполнений. Комиссии и исполнения — явно обозначенная модель.

Панель открывается на чистом графике с Bid/Ask. Нижние вкладки «График» и
«Настройки» одинаковы в двух отдельных приложениях. Старт/стоп и параметры
находятся в настройках; существующие команды доступны в выдвижной нижней панели.
Свайп вправо или вверх показывает более ранние свечи из доступного снимка;
pinch меняет масштаб свечей. Дополнительный график открывается рядом/ниже.
Подробности и ограничения проверок: [мобильный интерфейс](docs/MOBILE_PANEL_UI_RU.md).
Анализаторы паттернов, фигур, тренда и ликвидности пока не подключены — отображаются
только реальные данные цикла и настройки будущего отображения.
[Устройство, запуск и ограничения симулятора](docs/PAPER_CHART_RU.md).

## Настройка без запуска торговли

Windows VPS, MT5, 64-bit Python и зависимости из `requirements-tradfi-mt5.txt`.
Существующие SQLite, конфигурацию, identity счёта и долг сохраняйте. Новая установка использует
`tradfi_config.example.json` как основу `service.json`, с точными `terminal_path`,
`expected_server`, `expected_login`. Пример не содержит паролей и разрешений торговли.

В «Настройки (Блокнот)» задайте свой пароль в `web.password` внутри локального
`service.json`. Пустое поле не позволяет запустить панель. Для доступа только внутри
VPS (`127.0.0.1` или `::1`, без внешнего origin/прокси) минимум 5 символов;
для `web.public_origin` или объявленного прокси — минимум 32. Длинный уникальный пароль предпочтителен.
Файл содержит пароль открытым текстом: не отправляйте и не публикуйте его.
Если задана `TRADFI_WEB_PASSWORD`, она имеет приоритет; даже пустая/невалидная переменная
не вызывает переход к паролю из файла. `.env` автоматически не читается.
Короткий пароль нельзя выставлять наружу через прокси: loopback-binding не доказывает
отсутствие внешнего прокси. Удалённый доступ настраивается отдельно.
Старый `telegram_credentials_file` игнорируется; прежние локальные файлы секретов не читаются,
не копируются и не удаляются автоматически. `requests` остаётся для независимой проверки UTC.

```json
"web": {"enabled": true, "host": "127.0.0.1", "port": 8765}
```

После отдельного решения о запуске режим наблюдения:

```text
python tradfi_main.py --mode mt5 --service --config service.json
```

Панель на VPS: `http://127.0.0.1:8765/`. Вход по паролю, сессия 1 час,
HttpOnly/SameSite cookie, проверка Origin, ограничение попыток входа. В READ_ONLY торговые
действия запрещены. Действия идут через один owner-поток, durable receipt и revision;
неопределённый исход не является разрешением повторить запрос.

Для прежней общей установки предусмотрен [Windows мастер HTTPS](docs/HTTPS_PHONE_RU.md).
Его прежняя конфигурация не переносится автоматически в независимые каталоги;
в новых окнах эта операция пока не предлагается. Две публичные ссылки требуют
отдельной настройки. Существующая HTTPS-служба и её файлы остаются без изменений.
Он готовит проверяемый план, после отдельного подтверждения устанавливает собственную службу
Caddy с доверенным публичным IP сертификатом и задаёт `web.public_origin`.
Пароль для публичного доступа — минимум 32 символа. Backend остаётся `127.0.0.1:8765`,
proxy сохраняет Origin и передаёт этот Host; cookie получает Secure. Firewall не меняется.
Неизвестную старую службу мастер не останавливает. Ранние ошибки сохраняются в
`https-attempt.json`; диагностика показывает этап и код. Безопасное восстановление
подготовки требует отдельного подтверждения и сохраняет файлы без удаления.
При TLS-ошибке Python поддерживается выбор официального Caddy ZIP, скачанного браузером:
закреплённый SHA256 и AMD64 обязательны; TLS-проверки не отключаются. Для отдельно подтверждённого удаления
старой службы анализатора есть `tools/old-https-removal/REMOVE_OLD_ANALYZER_HTTPS.bat`.
Установка/проверки на реальном VPS здесь не выполнялись. Подробности отката и ограничений — в инструкции.
Адрес 127.0.0.1 в браузере телефона относится к самому телефону.

При завершении READ_ONLY с кодом 2 нажмите **Диагностика запуска** в новом установщике.
Она открывает безопасный отчёт в Блокноте, без PowerShell и торговых команд.
[Инструкция и ограничения](docs/STARTUP_DIAGNOSTICS_RU.md).

## Панель и ограничения

- Старт по закрытой M1, остановка новых входов, параметры начального входа и корзины.
- После доказанного первоначального SL — OCO на исходном входе и за ценой закрытия; по умолчанию 6 билетов × 0.01 на сторону. До SL встречная корзина не выставляется.
- SL корзины 1.50; TP1 обязателен в настройках, остальные расстояния заданы вручную или рассчитаны. После TP1 SL каждой части один раз переносится на её собственный фактический вход; trailing отсутствует.
- После каждого следующего SL новые BUY/SELL уровни — последняя фактическая цена закрытия ± отступ1.00 (настраивается).
- График M1, Bid/Ask, каждый билет, SL/TP, ордера, долг, прогноз покрытия и журнал.
- Удержание линии 500 мс и перетаскивание открывают предпросмотр; отправка только после подтверждения.
- Правки активного цикла сверяются с брокером. Число/объём билетов не изменяют открытые позиции.
- Ручное закрытие всей корзины: основной диапазон, от последнего фактического закрытия или ручные BUY/SELL; на одну следующую корзину либо до конца цикла. Требуется подтверждение, затем фактическая сверка закрытий.
- Обратная SL-лестница после подтверждённого переноса по TP1: доли i/N от собственного входа каждой оставшейся части к исполнимой цене; отмена возвращает каждому SL на его собственный вход. До подтверждённого TP №1 включение запрещено и кнопка недоступна.
- Ручная сверка сохраняет долг. Старый активный цикл блокирует новую стратегию без переноса/списания.

Торговля по-прежнему требует `--service --execute`, `enable_trading=true`,
`execution_contract=cycle_scoped_identity_v1`, точной identity,
`legacy_ea_removed=true`, `legacy_state_reconciled=true` и разрешений MT5.
Панель их не включает. Проверки времени, 24 часа, ownership и атомарный ledger сохранены.
`check_mt5.cmd` — отдельная диагностика только чтения, не сервис.
