# AI IMPULS · RECOVERY WEB 0.1.4-preview

Отдельная ветка от прямого MT5-варианта AI-IMPULS-TRAIDER (исходная основа 48130516).
Оформление и навигация взяты из основной веб-панели; источник данных, кнопки
и отображение диапазонов адаптированы под RECOVERY. В сборке нет Android-приложения,
виджета, старой стратегии, аналитики или Telegram.

## Чистая установка Windows VPS

1. Установите Python 3.13 x64 и MT5, войдите в MT5 самостоятельно.
2. Распакуйте архив целиком. Запустите START_RECOVERY_WEB.cmd. Оставьте
   отдельную папку AI_IMPULS_RECOVERY_WEB. Старая база и ключи не нужны и
   автоматически не переносятся.
3. Введите публичный IPv4 без https://. Нажмите «1. Подготовить всё».
   Мастер берёт проверенный Caddy с официального релиза или из указанного
   ZIP. Необязательный SETUP_PHONE_HTTPS.cmd сохраняет знакомый основной
   мастеру сценарий выбора официального ZIP. Он только готовит Caddy,
   без второй службы и без изменений брандмауэра. Для новой машины
   отдельно подтвердите предлагаемое узкое правило TCP 443 для Caddy,
   если оно нужно. Порт 8767 остаётся только локальным.
4. Запустите «Подключить веб-панель (без торговли)» и откройте показанный
   адрес по HTTPS. Введите ключ в самой панели. Этот режим подтверждает
   HTTPS и ключ, не счёт MT5. Ключ не сохраняется в браузере; не
   вставляйте его в URL, не отправляйте в чат.
5. Реальный процесс включается отдельно пользователем. До его запуска
   сверьте состояние прежнего счёта и исход предыдущей команды;
   остановите любого прежнего владельца, в том числе на другом VPS.
   Остановка и удаление VPS не отменяют биржевые ордера и не закрывают
   позиции. Незавершённое действие не повторяйте по догадке. Запуск
   реального режима не проверялся на Windows VPS.

## Веб-управление

В 0.1.3 исправлено отображение разрешения управления: после запуска
реального процесса подтверждённый ответ VPS передаёт панели признак
готовности к управлению. В режиме проверки связи кнопки по-прежнему
недоступны. Для отправки торговых команд остаются необходимы разрешение
для текущей вкладки и отдельное подтверждение каждой операции.

Панель показывает позиции, отложенные ордера и диапазоны RECOVERY.
У панели тёмный графитовый фон и приглушённо-белые кнопки, без внешних ресурсов. Нижние вкладки:
«Основная система», «Настройки» и «История».
Во вкладке «Настройки» → «Настройки RECOVERY» → «Лоты после полного SL»
можно сохранить отдельный лот для каждого шага после полного SL. Первый вход
остаётся 0,01, лимит остаётся 24. Запись доступна только без открытых позиций
на счёте, без активного/ожидающего переоткрытия цикла и без незавершённых
команд. Существующие отложенные ордера не изменяются. В диапазонном цикле
новый встречный ордер имеет приоритет над переносом SL поддержки после
подтверждения исполнения и исходного SL. Подхват готовой позиции не входит
в эту версию. После
явного включения управления можно подготовить один или два диапазона,
отменить диапазоны либо закрыть позицию и отменить соответствующий
диапазон, когда сервер разрешает действие. Перед отправкой показывается
отдельное подтверждение. Неподтверждённая команда не переотправляется;
её результат проверяется по номеру в журнале сервера. Нужен браузер с
Web Locks для координации вкладок (без этого доступен просмотр).
Автоматическая сверка или операция /reconcile не добавлена в веб-интерфейс.

Часы телефона не участвуют в разрешении команд. Сверка счёта, подтверждение
ответа сервера, текущая версия диапазонов и защита от повтора сохранены.
Прежний основной бот и веб-версия имеют отдельные файлы. На одном VPS и
под одним пользователем Windows они используют общий lock счёта и символа;
между разными VPS такая блокировка не действует.

Локальные тесты выполнялись без MT5/брокера. Эта сборка не является
подтверждением работы на реальном счёте.
