# AI Impuls — TradFi / MetaTrader 5

Торговый бот для `XAUUSD.s`, счёта UST hedging и прямого MT5 Python API.
Точка входа: `tradfi_main.py`. Управление — адаптивная веб-панель, работающая на телефоне.
Сервис на VPS продолжает работать, когда браузер закрыт. Telegram удалён из исполнения.

## Начальный вход AUTO

После Старт ожидается закрытие текущей M1. `Close > Open` задаёт BUY STOP по
`Close + INITIAL_ENTRY_DISTANCE`, `Close < Open` — SELL STOP по `Close - INITIAL_ENTRY_DISTANCE`.
По умолчанию новой установки: расстояние **1.00**, SL **3.00**, TP **0.25** в единицах цены.
Это не число минимальных тиков брокера. Некратные тику или недопустимые уровни не округляются скрыто.

Одинаковое направление следующих закрытых свечей сохраняет точный ожидающий ордер.
Противоположное направление отменяет его и, только после подтверждённой отмены и отсутствия
исполнения, создаёт новый STOP от нового Close. Doji (`Close == Open`) ничего не меняет.
Исполнение всегда имеет приоритет, в том числе во время отмены; позиция ждёт SL/TP.
UNKNOWN, отсутствие истории или противоречивые данные не разрешают повторный вход.
Пересечённый/слишком близкий начальный уровень не заменяется MARKET: ожидается новая M1.

После завершения цикла по TP бот ждёт новую закрытую свечу. `CYCLE_COOLDOWN_SECONDS`
задаёт дополнительную паузу; для новой установки — 0, сохранённое значение не перезаписывается.
При ненулевой паузе после её окончания ожидается следующее закрытие M1.
После SL работает новая корзина независимых билетов. Старые legacy/fixed и SEMI
не доступны в штатном сервисе. [Новая стратегия и миграция](docs/BASKET_RECOVERY_RU.md).

## Время после 1 ноября

На 2 ноября 2026 серверные часы Bybit — UTC+2. Уже существующий профиль
`bybit_live6_time_v1` учитывает переход автоматически; менять конфиг или часы
VPS на час не нужно. Внутри бота остаётся UTC, лимит цикла — 86400 секунд.
Серверное отображение не доказывает формат меток SDK: до read-only проверки
реальных tick/M1 сервис сохраняет `MT5_TIMESTAMP_SEMANTICS_UNVERIFIED` и не
разрешает новые входы. Подробнее: [проверка 2 ноября](docs/BASKET_RECOVERY_RU.md#время-на-2-ноября-2026).

## Настройка без запуска торговли

Windows VPS, MT5, 64-bit Python и зависимости из `requirements-tradfi-mt5.txt`.
Существующие SQLite, конфигурацию, identity счёта и долг сохраняйте. Новая установка использует
`tradfi_config.example.json` как основу `service.json`, с точными `terminal_path`,
`expected_server`, `expected_login`. Пример не содержит паролей и разрешений торговли.

В окружении **процесса сервиса** локально задайте `TRADFI_WEB_PASSWORD`: уникальный
случайный пароль минимум 32 символа. Пароль не помещается в URL, репозиторий или JSON конфигурации.
Без него штатный сервис с включённой панелью не запускается. `.env` автоматически не читается.
Старый `telegram_credentials_file` игнорируется; прежние локальные файлы секретов не читаются,
не копируются и не удаляются автоматически. `requests` остаётся для независимой проверки UTC.

```json
"web": {"enabled": true, "host": "127.0.0.1", "port": 8765}
```

После отдельного решения о запуске режим наблюдения:

```text
python tradfi_main.py --mode mt5 --service --config service.json
```

Панель на VPS: `http://127.0.0.1:8765/`. Вход по паролю, сессия 1 час,
HttpOnly/SameSite cookie, проверка Origin, ограничение попыток входа. В READ_ONLY торговые
действия запрещены. Действия идут через один owner-поток, durable receipt и revision;
неопределённый исход не является разрешением повторить запрос.

Для телефона нужен отдельно настроенный **HTTPS reverse proxy** к этому loopback-порту.
Добавьте в `web` точный `public_origin`, например `https://bot.example.org` (без завершающего `/`).
Proxy должен передавать оригинальный Origin и переписывать Host в `127.0.0.1:8765`;
доступ к upstream остаётся только локальным. В этом режиме cookie получает Secure.
Произвольные X-Forwarded-* заголовки не включают доверие. Нужны реальный домен,
сертификат, доступ к VPS и согласованные сетевые правила; этот патч их не настраивает.
Адрес 127.0.0.1 в браузере телефона относится к самому телефону.

## Панель и ограничения

- Старт по закрытой M1, остановка новых входов, параметры начального входа и корзины.
- Противоположная корзина на SL начальной позиции: по умолчанию 6 независимых билетов × 0.01.
- SL корзины 1.50; ступенчатые TP покрывают фактический денежный долг, SL не подтягивается.
- После первого SL корзины расширение на 1.00 один раз; уровни сохраняются между повторными входами.
- График M1, Bid/Ask, каждый билет, SL/TP, ордера, долг, прогноз покрытия и журнал.
- Удержание линии 500 мс и перетаскивание открывают предпросмотр; отправка только после подтверждения.
- Правки активного цикла сверяются с брокером. Число/объём билетов не изменяют открытые позиции.
- Ручная сверка сохраняет долг. Старый активный цикл блокирует новую стратегию без переноса/списания.

Торговля по-прежнему требует `--service --execute`, `enable_trading=true`,
`execution_contract=cycle_scoped_identity_v1`, точной identity,
`legacy_ea_removed=true`, `legacy_state_reconciled=true` и разрешений MT5.
Панель их не включает. Проверки времени, 24 часа, ownership и атомарный ledger сохранены.
`check_mt5.cmd` — отдельная диагностика только чтения, не сервис.

```text
python -m unittest discover -s tests
node --check web/basket-panel/panel.js
```

Тесты используют искусственный брокер и подставные MT5 API. Реальные сделки,
VPS, Android/HTTPS и брокерская доступность требуют отдельной проверки перед вводом в эксплуатацию.
