# FULL TRAIDE

RECOVERY для MetaTrader 5 с локальным пультом на Windows VPS. Python ведёт торговую цепочку. Один советник MT5 сообщает о позициях, ордерах и истории. Второй проверяет защитный SL от фактической цены входа и переносит его к цене входа при достижении заданного порога.

## Установка на новый VPS

1. Откройте [пошаговую инструкцию на русском](INSTALL_VPS_RU.md). Она охватывает установку Python и MT5, подключение двух советников и первый запуск.
2. Скачайте [установщик для Windows x64](dist/RECOVERY-Python-Windows-98fe241ccd57a411.zip?raw=1) и [контрольные суммы SHA-256](dist/RECOVERY-Python-98fe241ccd57a411-SHA256.txt). Распакуйте установщик целиком.
3. После установки откройте «RECOVERY — Пульт управления» на рабочем столе. Кнопка «Старт» запускает обработку. Режим входа выбирается отдельно.

В режиме «Ждать рыночную позицию» Python сопровождает вашу ручную позицию. После полного ручного закрытия он отменяет оставшийся встречный STOP этой цепочки. Когда MT5 подтвердит отмену, Python возвращается к ожиданию следующей ручной позиции, если повтор включён. Если STOP успел исполниться, Python сверяет результат и продолжает сопровождение.

Если брокер отклоняет перенос цены встречного STOP, пульт показывает отказ. Когда MT5 подтверждает, что ордер остаётся выставленным, пульт сообщает о прежней цене. При исполнении ордера RECOVERY сверяет историю по его тикету.

После фактического исполнения RECOVERY проверяет защитный SL каждой привязанной позиции. Целевая дистанция от цены входа равна меньшему из двух значений — настройке «Дистанция SL» и 0,80 единицы цены. Более близкий SL и текущий TP сохраняются. Если брокер пока не допускает целевой уровень, помощник ждёт допустимой котировки. Исполнение самого SL может пройти с проскальзыванием.

## Состав сборки

При торговом событии в MT5 помощник уведомляет локальный процесс Python. Контроллер перечитывает состояние ордеров и позиций, а также сверяет их периодически. У торгового процесса RECOVERY обычный приоритет Windows. Окно пульта и служба, которая записывает состояние и квитанции команд, работают в двух отдельных процессах с пониженным приоритетом. Денежный результат смотрите в истории счёта MT5. Пульт показывает ход торговой цепочки без расчёта прибыли и убытка.

Сборка `98fe241ccd57a411` содержит готовые советники `RecoveryPythonVerifier.ex5` и `RecoveryPythonSL.ex5`, локальный пульт и библиотеки MetaTrader5 и NumPy для Python 3.13 x64. Настройки счёта и пресеты для графиков установщик создаёт на новом VPS. Значения по умолчанию для XAUUSD.s — начальная дистанция SL 0,80 и порог переноса к цене входа 0,40 в единицах цены.
