# Форма начальных триггеров RECOVERY

`recovery_ranges.html` и `recovery_ranges.mjs` можно подключить только к
существующей защищённой панели. Подключение не делает запросов само.
После отрисовки один раз вызови `controls.refresh()` для чтения контекста:

```js
const controls = wireRecoveryRanges(form, {request: panelRequest});
await controls.refresh();
```

`panelRequest(url, init)` — существующий доверенный адаптер к запросам
панели на её же адресе. Он использует защищённую сессию пользователя и
серверную проверку CSRF. Внутренний bearer не передавать браузеру, не хранить
в JS. Если панель удаляет форму, вызвать `controls.disconnect()`.

Форма позволяет выбрать один или два диапазона, сторону BUY/SELL каждого,
и ввести точную цену текстом через точку. Отправка только после кнопки
«Подтвердить и отправить», с текущими ID сеанса, контекста и поколения.
Цена не округляется; допустимый шаг проверяет EA. Никаких линий или
рыночных входов. Отправка записывает команду в очередь, подтверждение
принятия не выдаётся за выполнение.

Пока результат неясен, кнопка «Проверить состояние» читает статус
исходного ID и его сеанса. Повторного POST нет. После подтверждённого
нового сеанса старая команда не переносится. При закрытии формы её
локальный контекст не восстанавливается; запросов на открытие или
повторную отправку на фоне нет.

`node --test test_recovery_ranges.mjs` проверяет работу модуля с тестовым
интерфейсом и имитатором HTTP. Это не подключённая панель и не испытание MT5.
