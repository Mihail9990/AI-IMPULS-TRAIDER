# Сборка исходников RECOVERY EA в MetaEditor

Это **не установщик и не релиз для торговли**. Сборка работает в отдельной
временной папке, не запускает MT5, не подключает советники к графикам, не
отправляет ордера и не изменяет настройки или каталог данных терминала.

Нужны Git, Python 3.13 x64 и установленный официальный MetaEditor. Скачивать
исполняемые файлы этим скриптом нельзя. Пример ниже запускается в PowerShell
из корня локальной копии GitHub, содержащей эти инструменты и точный коммит
с проверяемыми исходниками.

```powershell
$Commit = (git rev-parse HEAD).Trim() # checkout заранее закреплён на переданном коммите
$Deploy = 'design\recovery-ea\deployment'
$Build = Join-Path $env:TEMP ('recovery-ea-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $Build | Out-Null
$Archive = Join-Path $Build 'candidate-src.zip'
$Results = Join-Path $Build 'compile-results'
$MetaEditor = 'C:\Program Files\MetaTrader 5\metaeditor64.exe'  # Укажи свой путь
$PackJson = py -3 "$Deploy\source_build.py" package --repo . --commit $Commit --out $Archive --trader execution/RecoveryTrader.mq5
if ($LASTEXITCODE -ne 0) { throw 'ZIP сборки не создан' }
$Pack = $PackJson | ConvertFrom-Json
& "$Deploy\Compile-RecoverySources.ps1" -MetaEditor $MetaEditor -Archive $Archive `
  -Commit $Commit -ArchiveSha256 $Pack.zip_sha256 -Results $Results -Mode candidate
```

Для передачи ZIP с другого компьютера берите SHA-256 у доверенного
публикатора отдельно от ZIP. Не вычисляйте «ожидаемый хеш» из неизвестного
архива. Скрипт дополнительно проверяет коммит манифеста и SHA-256 каждого
исходника. При повторении задайте **новые** пути к ZIP и папке результата:
инструменты не перезаписывают существующие результаты.

Режим `candidate` допускает ровно три входных файла по фиксированным
путям: `verifier/RecoveryVerifier.mq5`, `watcher/RecoveryPriceWatcher.mq5`,
`execution/RecoveryTrader.mq5`. Советники не запускаются при компиляции.
ZIP содержит только исходники и их локальные зависимости из указанного
коммита, без правок из рабочей папки. Манифест схемы 2 обязателен.
Сборка внутреннего диагностического скрипта не является заменой сборки
этих трёх советников или частью комплекта для установки.

Упаковка и распаковка проверяют, что ZIP содержит ровно зависимости из
локальных строк `#include "...mqh"` для указанных целей. Лишние исходники,
псевдонимы путей Windows, системные/неявные include, импорты DLL и внешние
ресурсы не поддерживаются. Бинарники, логи, конфиги и ключи не попадают
в архив исходников.

Результат компиляции: `compile-report.json`, исходные логи компилятора и
новые `.ex5` только для успешно скомпилированных целей. Для каждой роли
отчёт связывает точный путь и SHA-256 исходника, нового лога и EX5. В
отчёте также указываются SHA-256 исполняемого файла MetaEditor и числовые
версии файла и продукта из его
[ресурса версии Windows](https://learn.microsoft.com/en-us/windows/win32/api/verrsrc/ns-verrsrc-vs_fixedfileinfo).
В `compile-report.json` пути машины не записываются. Если файл MetaEditor
изменился до или во время компиляции, подтверждённый EX5 для этой цели
не выдаётся; если версии нельзя прочитать до запуска, компиляция не
начинается. Изменение какого-либо распакованного исходника во время сборки
также не даёт подтверждённый EX5. Эти сведения идентифицируют сборку, но не проверяют подпись
издателя. Если результат неизвестен или
лог неполный, сборка считается неуспешной. Запускается только
[компиляция через MetaEditor](https://www.metatrader5.com/en/metaeditor/help/beginning/integration_ide);
это не проверка фактического исполнения торговых заявок. Для выдачи
финального ZIP требуются сборка трёх рабочих EA и проверка чистого установщика;
демо-прогон не является обязательной стадией. Укажите, если исполнение сделок
не проверялось.
После успешной компиляции кандидата PowerShell проверяет комплект
всех трёх локальных результатов. Ту же проверку консистентности
можно выполнить отдельно, без MT5 или MetaEditor, через
`source_build.py check-candidate-results --archive <ZIP> --commit <COMMIT> --archive-sha256 <SHA256> --results <ПАПКА>`.
Проверяются совпадение связей и файл лога с нулём ошибок для каждой роли,
но не подпись издателя, загрузка на график или действия у брокера. Подлинность
сборки зависит от доверенного источника и компьютера компиляции.

Оригинальные логи с путями не распространяйте публично. Для отладки
передавайте только очищенные фрагменты; отредактированный лог уже
не совпадает с SHA-256 исходного файла.

Проверка оболочки на Linux: `python -m unittest -v test_source_build.py`.
Она проверяет упаковку и имитирует MetaEditor, а нативную сборку Windows
не подтверждает.
