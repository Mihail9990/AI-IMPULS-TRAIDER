# RECOVERY EA: установка на чистый Windows VPS

Это контракт будущего установщика и приёмочный список, не готовый установщик.
Старый VPS не открываем и не меняем. Не переносим его файлы, базу, ключи, адреса,
логины, Magic, Chart ID и журналы. Всё создаётся на новом VPS с нуля.

В качестве примера мастера просмотрен RECOVERY WEB 0.1.7-preview: отдельная папка,
подготовка Caddy, веб-панель без торговли, локальный внутренний порт. Сборка
0.1.7 использует другой исполнитель; не устанавливать её поверх двух EA и не
включать её Python-торговлю как запасной путь.

## Порядок установки и проверок

1. Новый архив распаковывается целиком в отдельную папку. Мастер проверяет
   Windows x64 и доступные терминалы MT5. Если терминалов несколько, показывать
   их для выбора; не угадывать по пути или по данным прежнего VPS. Пользователь
   сам входит в MT5. Распознать активный терминал, счёт/тип счёта, сервер и
   символ из выбранного подключённого MT5; при неопределённости попросить
   выбрать, а не подставлять значения. Сохранить новый профиль локально.
2. Создать пустую базу состояния и приватные рабочие папки. Сгенерировать новый
   случайный ключ входа в веб-панель один раз, показать локально при настройке,
   никогда не включать в ссылки, журналы или экспорт. Ключ не заменяется при
   обычном перезапуске или повторе того же этапа установки. Доступ к файлам
   ограничен учётными записями установленного сервиса и администратора.
3. Настроить панель по HTTPS на явно выбранном новом адресе, сервер панели
   слушает только loopback. Не открывать внутренний порт наружу. При
   необходимости отдельно согласовать узкое правило для входящего HTTPS;
   установка не меняет брандмауэр молча. Не включать торговлю для проверки
   ключа, HTTPS или доступа с телефона.
4. Скомпилированные EA ставятся в каталог данных выбранного MT5. Две роли
   работают на разных графиках: торговый EA и EA сверки без торговых вызовов.
   Использовать новые идентификаторы профиля и запуска. Проверка подключения
   не предполагает наличия прошлой сделки или установленного SL. Первый
   запуск в режиме наблюдения без отправки ордеров: Python показывает
   результат проверки обоих EA и не имеет пути записи ордеров.
5. Если на подключённом **брокерском счёте** уже есть позиции или ордера,
   чистая машина не отменяет их. Отобразить обнаруженное состояние, не менять
   его при установке и не создавать автоматически дубликаты. Отсутствие
   истории на новом VPS не является подтверждением исхода операции.
   Включение режима, способного отправлять ордера, выполняет сам пользователь
   отдельно после проверок, а не кнопка «Установить» или подключение панели.

## Что должно пройти до выпуска

На действительно чистой Windows проверить полный путь от распаковки до
доступной HTTPS-панели и связки двух EA на демо без торговых запросов.
Проверить повтор установки после сбоя: не появляются дубликаты процессов и
не меняется ключ. Проверить несколько установок MT5, неверный аккаунт,
пустой счёт без истории, обрыв связи и возврат без повторной отправки команд.
Отсутствие старого VPS или его данных не должно мешать установке. Фактических
прогонов этого мастера пока нет.
