# Декодирование команды панели в MQL

`RecoveryDecodePanelCommand` принимает неизменённый ASCII JSON из
`channel.encode()`, ID из **имени отдельного файла** и доверенные UUID
области, загрузки, контекста и поколения от текущего владельца. Операция:
`manual_wait`, `manual_cancel` (пустой payload) либо `configure_ranges`
(один/два диапазона с уникальными номером 1/2, BUY/SELL и положительной
десятичной ценой). Порядок диапазонов в массиве сохраняется. В результате
цена уже в целых тиках; BUY = 1, SELL = -1. Шаг цены передаёт терминал,
а не браузер; ручные команды его не используют.

Парсер принимает строго канонические ключи, разделители и скаляры,
не допускает пробелов вне значения, дубликатов, неизвестных полей или
числовых преобразований JSON в строку. Для времени проверяется только
форма целого int64, не возраст заявки. Цены без ведущих нулей, экспонент,
пробелов, округления и знака. Используется точное деление десятичных цифр;
отсутствие точного шага или более 10^12 тиков даёт отказ, не коррекцию.
SHA-256 проверяется на документе без поля `content_sha256`, без NUL или
переупаковки. Хеш обнаруживает повреждение/подмену содержимого с прежним
хешем; **это не авторизация** и не замена приватным ACL.

При отказе выход очищен. Сам декодер не читает файлы и не пишет квитанции;
не выполняет команды и не отправляет ордер. Владельцу ещё нужно безопасно
читать только текущую папку сеанса с проверкой байтов, сверять фактический
контекст и учёт ID при применении команды. Не считать успешный декод
разрешением на повтор.

`python execution/test_panel_command_wire_compat.py -v` из
`design/recovery-ea`: Python формирует канонические входы и контрольный
SHA-256, строгий C++ хост-прогон использует OpenSSL на месте штатного
`CryptEncode`. Компиляция MetaEditor не выполнена.
