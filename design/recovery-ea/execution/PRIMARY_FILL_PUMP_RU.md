# Опрос первого входа диапазона

Создать в текущем сеансе один `RecoveryPrimaryFillPump` (RPP_UNUSED)
на точно известный тикет первого STOP. Передать состояние диапазона,
параметры, три новые nonce, тег публикации и `RecoveryPrimaryFillBinding`.
В поле history.position_identifier при запуске должен быть нуль. В
RR_NEW владелец передаёт точную заявку, которой принадлежит известный
тикет. В RR_WAIT ожидаемый ордер берётся из подтверждённой записи
диапазона, а routed должен быть RR_NONE.

Из таймера вызывать `RecoveryPrimaryPumpStep`. Пока исторического
подтверждения нет, автомат читает только известный тикет. Он не полагается
на callback, исчезновение ордера из текущих или совпадение цены. Историческое
FILLED или CANCELED с положительным остатком может начать опрос только
при совпадении условий STOP и наличии точного идентификатора позиции.
Локальный ответ не подтверждает вход, а отмена не отправляется этим кодом.

Далее по одному шагу запрашивает точный ответ независимого сверщика,
историю по связанной позиции и полный снимок. Три ответа сверяются по
сеансу, связанным идентификаторам и номерам. Только `RPP_PROOF` выдаёт
`RRFilled` (один раз): владелец передаёт его вместе с `pump.binding` в
обработчик первого входа. Автомат сам не меняет диапазон и не отправляет
ордера. Для частичного CANCELED окончательная сверка всё равно требует
точного отменённого остатка, входной истории, текущей позиции и отсутствия
работающего остатка.

RPP_WAIT означает отсутствие читаемого подходящего ответа (в том числе
открытый или пока частичный ордер). При несогласованности независимой
сверки или смене контекста — RPP_STOPPED. Ни таймер, ни ошибки публикации
не переотправляют запрос и не повторяют торговую заявку. Без часов,
блокировок времени и чтения старого сеанса. Выделение nonce и реакция на
остановку остаются у владельца.

`python execution/test_primary_fill_pump_compat.py -v` проверяет автомат
через C++/UBSan и подменённые API терминала. Точный разбор отчётов и расчёт
первого входа покрываются отдельным `test_primary_fill_compat.py`. Проверка
MetaEditor не выполнена.
