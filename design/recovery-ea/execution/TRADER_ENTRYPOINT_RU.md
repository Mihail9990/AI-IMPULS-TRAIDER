# Точка входа основного советника RECOVERY

`RecoveryTrader.mq5` подключает текущий `RecoveryChartRuntime.mqh` к одному
графику MT5. Инициализация не выставляет, не изменяет и не отменяет ордера;
после подтверждения нового пустого контекста таймер только начинает
принимать входящие команды. Действующие заявки брокера при старте/останове
не импортируются и не меняются.

- Для трёх графиков используется одна свежая серия входов из
  `deployment/role_launch.py`, см. `deployment/ROLE_LAUNCH_RU.md`.
  Основной EA требует два разных ID наблюдателей, отличных от его графика,
  и проверяет совпадение символа. Роли запускаются на том же терминале.
  Общее значение для наблюдателей вычисляется из `ProfileScope` и
  `InstanceSeed`; два отдельных идентификатора ролей основной EA сам
  вычисляет из этой же серии. Предыдущий seed не использовать после
  перезапуска. Проверка ID графика не является проверкой наличия работающего
  советника на нём: готовность прямого обмена ещё не проверена.
- `ExpectedLogin`, `ExpectedServer` и `ExpectedSymbol` сверяются точно.
  Основной EA использует согласованный hedging-счёт и закреплённый
  `FixedTimeframe` (по умолчанию M1). Штатные разрешения MT5 и счёта
  проверяются; советник не включает торговлю сам.
- `InitialSLDistance` (0.80) и единственный `SupportThreshold` (0.40)
  измеряются в единицах цены. Порог поддержки переводит SL на фактическую
  цену входа; первого уровня нет. Требуется точная кратность шагу цены.
  Параметры и 24 лота из `LotSchedule` фиксируются на текущий сеанс.
  Это входы советника, пока веб-владелец настроек не подключён.
- Временная потеря соединения не вызывает отправку и не меняет сеанс.
  Подключённый терминал с другим счётом, изменённым графиком/контекстом или
  снятым разрешением MT5 прекращает работу этого сеанса. Для нового
  запуска требуется новая серия входов; восстановления стратегии нет.
  Нет срока годности по часам, сверки телефона или обязательного демо.
  Остановка не отменяет заявки брокера и сама по себе не закрывает позиции.

Офлайн: `python -m unittest -v test_trader_entrypoint_compat` из этого
каталога. Это строгая C++ проверка обработчиков с заменой MT5 и контроллера,
не сборка MetaEditor. Исходник для интеграции, не релиз и не инструкция
включить реальные сделки.
