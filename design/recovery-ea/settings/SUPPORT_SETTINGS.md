# Настройки двух порогов сопровождения

В веб-настройках редактируются два положительных расстояния движения цены и переключатель `support_first_enabled` (по умолчанию включён):

- `support_first` по умолчанию `0.25`: первый перенос SL.
- `support_second` по умолчанию `0.40`: перенос SL на цену входа.

Значения задаются **в единицах цены**, десятичными строками с точкой, а не числом
пунктов. При включённом первом переносе проверяется
`0 < support_first < support_second` и точное попадание обоих расстояний на шаг
цены инструмента. Округления нет. Первый перенос сохраняет фиксированный
отступ SL от цены входа `0.25`, независимо от выбранных порогов. В снимке EA
поля называются `support_first_ticks`, `support_second_ticks`,
`support_offset_ticks`.

Если первый перенос выключен, действует только перенос SL на цену входа по
второму порогу; он проверяется независимо. Первый сохранённый порог не
затирается и не редактируется, пока выключен. В снимок EA попадает
`support_first_ticks=0`, `support_offset_ticks=0` как признаки отключённого
этапа. При включении первого переноса снова проверяются его сетка, порядок
порогов и сетка отступа `0.25`.

Панель получает размер тика выбранного инструмента и состояние активного
поколения от сервера; браузер не может подставлять их. Оба порога сохраняются
вместе для следующего поколения. Редактирование при активном или неизвестном
состоянии отклоняется, сохранённый снимок уже действующего поколения не
меняется. После подключения панели проверку состояния, запись настроек и
подготовку нового поколения нужно сериализовать в одном владельце процесса.

Это Python-модель и готовый к встраиванию локальный HTML/JS-фрагмент для
будущих веб-настроек; фрагмент не делает сетевых вызовов. Текущий сайт, запись
на сервере и V1 файл команды не менялись. Панель должна передать фрагменту
свои начальные настройки и разрешение редактирования, а сама использовать
существующую аутентифицированную обработку сохранения.

Офлайн-проверки из этого каталога:
```
python -m unittest -v test_support_settings.py
node --test test_support_controls.mjs
```
