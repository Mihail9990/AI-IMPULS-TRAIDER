# Один порог переноса SL на цену входа

В веб-настройках есть единственный порог `support_threshold`, по умолчанию
`0.40` **в единицах цены**. При достижении порога SL переносится сразу
на фактическую цену исполнения позиции. Отдельного промежуточного переноса,
расстояния до входа и переключателя больше нет.

Python принимает положительную десятичную строку с точкой, проверяет точное
попадание порога на шаг цены инструмента и ничего не округляет. В выходном
снимке для действующего контракта EA это `support_first_ticks=0`,
`support_second_ticks=порог`, `support_offset_ticks=0`. Два нуля являются
внутренними маркерами отключённого прежнего этапа, не настройками панели.

Редактирование доступно только в уже предусмотренном сервером состоянии
idle. Размер тика и состояние предоставляет владелец RECOVERY, не браузер.
Сохранение настройки не переопределяет снимок активного поколения, не
считывает старые заявки и не вводит проверок по часам.

См. `SUPPORT_RUNTIME_RU.md` о сохранении и подключении формы.
