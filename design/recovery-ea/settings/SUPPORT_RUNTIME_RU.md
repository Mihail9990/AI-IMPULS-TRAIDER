# Сохранение настроек сопровождения RECOVERY

Серверный адаптер для нативной ветки `recovery-ea`, без импорта MT5 и без
отправки заявок. Старая ветка веб-панели не изменена. В протокол V1 команд
ничего не добавляем.

- `GET /api/recovery/ea/support-settings` читает сохранённые значения,
  `revision` и указание `editable` для отрисовки формы.
- `PUT` на тот же путь принимает ровно `revision`, `support_first`,
  `support_second`, `support_first_enabled`. Смена состояния или устаревшая
  ревизия даёт 409. При 409 обновить настройки, не повторять сохранение
  автоматически. Использовать существующий защищённый вход, с серверной
  проверкой сессии и CSRF; внутренний ключ не передавать браузеру.
- По умолчанию первый перенос включён: `0.25` и `0.40`. Когда первый
  выключен, сохранённое старое значение не изменяется, даже при подменённом
  запросе; остаётся второй порог. Уже выданный снимок не меняется.
- Настройки сохраняются отдельно от команд в приватном каталоге нового
  профиля. Запись происходит атомарной заменой файла после его сброса на
  диск. Это проверено для повторного открытия процесса и ошибок записи;
  стойкость к потере питания не сертифицирована.

## Контракт владельца состояния

До подключения маршрута нужен **один процесс-владелец резервирования**:
создать `SupportStore(private_path, owner_lock, observe)`, где
`owner_lock` — его общий `RLock`, а `observe` проверяет настоящее состояние
поколения и возвращает точный шаг цены выбранного инструмента. Владельцу
нужно применить тот же замок к смене контекста и затем резервировать новое
поколение *внутри* `locked_next_generation()`. Внутри этой секции снимок
сопровождения в тиках привязывается к тому же неизменяемому поколению, а
новое состояние владельца перестаёт быть idle до выхода из секции.

Не использовать копию публичного состояния `Channel.state()`: роутер V1
не подтверждает ни отсутствие действующего цикла, ни размер тика, ни
атомарность перехода. Процессный замок Python сам по себе не блокирует
торгового EA, другие воркеры и другие процессы. Если резервирует EA, до
подключения формы нужно согласовать единый протокол подтверждения владения.
До этого маршруты не монтируются; торговый советник и VPS не меняются.

`python -m unittest -v test_support_runtime` запускает проверки HTTP и
хранилища без MetaTrader. Тестовый ключ из фикстур не использовать
на сервере. Реальный вход и форма в панели здесь не подключены.
