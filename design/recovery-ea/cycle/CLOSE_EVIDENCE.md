# Подтверждённый выход из позиции

`RecoveryCloseEvidence.mqh` проверяет нормализованные полные наблюдения
истории и инвентаря. `RecoveryCloseWire.mqh` связывает их с двумя исходными
запросами EA сверки и подаёт проверенный выход прямо в `RCApplyClose`.
Никаких запросов брокеру, сроков действия, торговли или настроек пользователя.

- Одна локальная операция сверки связывает два исходных nonce с точным счётом,
  символом, поколением, экземплярами EA и графиком сверки. Порядковые номера
  наблюдений не являются часами. Контракт локальной привязки хранится в памяти владельца сеанса
  отдельно и не может формироваться из полученного ответа.
- Из истории нужен завершённый входной ордер и объём всех его ENTRY_IN сделок,
  равный ранее подтверждённому входу. Для частичного входа с отменой остатка
  начальный объём минус остаток должен точно совпасть с исполненным объёмом.
  Неизвестный вид закрытия, другой вход, несовместимая история и неточный объём
  не завершают цикл. Двойное появление тикета в одном wire отклоняется читателем;
  в нормализованном ядре полностью совпадающая строка не повторяет объём,
  противоречащая строка остаётся нерешённой.
- Исчезновение позиции без всех точных выходов не доказывает закрытие. При
  неполном выходе учитывается отдельный снимок остатка. Закрытие признаётся
  только при нулевом остатке и подтверждённом полном объёме. Цена фактического
  исполнения не подменяет DEAL_SL и не используется как уровень стопа.
- Полный SL и SL поддержки различаются по одному точно совпадающему типу
  защиты из подтверждённого журнала текущего сеанса. Неоднородные сделки,
  совпадение сразу с двумя типами и неподтверждённый перенос не меняют счётчик.
  При SL поддержки переоткрытие считается от подтверждённого SL. Точный TP
  можно распознать, но автоматическое действие по нему не реализовано.
  EXPERT не считается ручным выходом по одному коду причины.

Владелец текущего сеанса ведёт подтверждённый журнал защиты, связывает
позиции и запросы и фиксирует переход с намерением в памяти. Снимки
терминала не атомарны; предыдущий сеанс не восстанавливается.

Хост-тест из корня репозитория (без MetaEditor):
```sh
python3 design/recovery-ea/cycle/test_close_evidence_compat.py
```
