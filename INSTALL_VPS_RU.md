# FULL TRAIDE на Windows VPS

Сборка RECOVERY `a58dcb94c49068e0` работает через локальный пульт Python и два помощника на графиках MetaTrader 5. Для установки войдите на VPS под тем пользователем Windows, который будет запускать терминал и пульт.

## 1. Подготовьте терминал и Python

1. Установите настольный **MetaTrader 5 для Windows x64** от своего брокера. Войдите на нужный **хеджинговый** счёт с торговым паролем. Проверьте номер счёта и точное имя сервера. Найдите нужный инструмент в «Обзоре рынка» и запишите его имя вместе с суффиксом, если он есть. Для счёта Bybit используйте инструкцию брокера. [Настройка счёта MT5 CFD в Bybit](https://www.bybit.com/en/help-center/article/How-to-Get-Started-with-MT5-CFD-Account)
2. Подготовьте два пути. Первый ведёт к `terminal64.exe` этой установки. Второй показывает сам MT5 в меню **Файл → Открыть каталог данных**. Скопируйте путь открывшейся папки целиком. Внутри неё должна быть `MQL5\Files`.
3. Установите полный **CPython 3.13 x64**. Для проверенной версии 3.13.17 на странице Python выберите **Windows installer (64-bit)** и оставьте компонент **Tcl/Tk and IDLE**. При нестандартной папке установки оставьте также Python Launcher. Установщику нужны `python.exe` и `pythonw.exe`. Проверка `py -3.13 -m tkinter` должна открыть тестовое окно, которое можно закрыть. [Python 3.13.17 для Windows](https://www.python.org/downloads/release/python-31317/)
4. Для новой независимой установки выберите **новый уникальный Magic** — положительное целое число, которое другие роботы на этом счёте не используют. Система использует его для распознавания своих заявок. Пароль от брокера вводится только в MT5.

**При переезде со старого VPS** дождитесь завершения текущего цикла. Сверьте в MT5, что у стратегии нет позиций и действующих заявок, отмените ожидание и нажмите «Стоп». Дождитесь статуса паузы. Закрытие окна пульта или отключение от RDP оставляет контроллер работающим. Перед запуском на новом VPS завершите контроллер на старом, например выйдите из старого сеанса Windows, и исключите его повторный запуск. Одной стратегией на счёте должен управлять один экземпляр. Для переезда после завершения цикла используйте новые локальные пресеты на новом VPS. Местную историю и индивидуальные настройки прежнего пульта сохраните отдельно.

## 2. Скачайте и установите RECOVERY

Скачайте оба файла из этой ветки. Если GitHub открыл карточку ZIP, нажмите **Download raw file**.

- [Установочный ZIP для Windows](./dist/RECOVERY-Python-Windows-a58dcb94c49068e0.zip)
- [Контрольные суммы SHA-256](./dist/RECOVERY-Python-a58dcb94c49068e0-SHA256.txt)

1. В PowerShell откройте папку со скачанным архивом и выполните команду.

   ```powershell
   Get-FileHash -Algorithm SHA256 .\RECOVERY-Python-Windows-a58dcb94c49068e0.zip
   ```

   Ожидаемая сумма Windows ZIP — `0732e6fe5982cb346ce602a536ffa01a464b9708119b419d30f678f883ff9e37`.
2. Распакуйте **весь ZIP** в локальную папку и запустите `Install.cmd` двойным щелчком. Для проверки комплекта перед установкой можно открыть PowerShell в распакованной папке и выполнить `.\Install.cmd --verify-only`. MetaTrader5 и NumPy для Python уже включены в ZIP.
3. На новом VPS введите путь к `terminal64.exe`, путь к каталогу данных MT5, номер счёта, сервер, символ и выбранный Magic. Установщик сам создаст `PythonScope` и оба пресета. При обновлении ранее установленного RECOVERY он сначала проверит сохранённую привязку. Если сообщит о работающем владельце, другой версии помощника или отличающемся пресете, завершите подготовку прежней установки по разделу «Перед обновлением» в `README_RU.txt` из ZIP.
4. Дождитесь сообщения **«Готово»**. На рабочем столе появится **«RECOVERY — Пульт управления»**. Оба помощника установятся в `MQL5\Experts\RECOVERY-Python` в выбранном каталоге данных. Папку их пресетов можно открыть, вставив в адресную строку Проводника `%LOCALAPPDATA%\AI-IMPULS-RECOVERY\control\python-v1\presets`.

Для обновления с предыдущей Python-сборки дождитесь пустого цикла и подтверждённой паузы, закройте пульт и завершите прежний супервизор по инструкции в README_RU.txt внутри ZIP. Оба помощника MT5 и их пресеты совпадают с предыдущей сборкой и остаются на месте. Если установщик обнаружит более старый или изменённый файл EX5, он укажет его имя. Порядок сохранения старого файла и повторного подключения помощника описан в README_RU.txt.

## 3. Прикрепите двух помощников к MT5

Откройте **два отдельных графика одного и того же настроенного символа**. Можно выбрать M1 на обоих. В окне «Навигатор» щёлкните правой кнопкой по «Советники» и выберите «Обновить». В каталоге `RECOVERY-Python` появятся оба помощника. Перетащите первого советника из «Навигатора» на первый график. В открывшемся окне задайте разрешение на вкладке **«Общие»**, на вкладке **«Входные параметры»** нажмите **«Загрузить»**, открыв одноимённый файл из папки пресетов. Нажмите **OK**. Повторите эти действия для второго советника на втором графике.

| График | Советник и пресет | Разрешение торговли в свойствах советника |
| --- | --- | --- |
| Первый | `RecoveryPythonSL` → `RecoveryPythonSL.set` | **Включить** «Разрешить алгоритмическую торговлю». Помощник выполняет порученное изменение SL. |
| Второй | `RecoveryPythonVerifier` → `RecoveryPythonVerifier.set` | **Оставить выключенным**. Этот помощник читает позиции, ордера и историю для независимой сверки. |

В обоих пресетах четыре поля — `ExpectedLogin` (номер счёта), `ExpectedServer` (сервер), `ExpectedSymbol` (символ) и `PythonScope` (общая привязка этой установки). Значения на обоих графиках должны совпадать. Magic хранится в настройках Python и отдельно в советники не вводится. Для этой сборки достаточно этих двух графиков. [Подключение советника к графику в MT5](https://www.metatrader5.com/en/terminal/help/algotrading/trade_robots_indicators)

Когда готовы разрешить работу стратегии, включите общий переключатель **«Алготрейдинг»** в MT5. В **Сервис → Настройки → Советники** разрешите алгоритмическую торговлю и снимите флажок **«Запретить автоматическую торговлю через внешний Python API»**. В английском интерфейсе этот флажок называется **Disable automatic trading through the external Python API**. Локальные разрешения на двух графиках оставьте как в таблице. Проверьте, что обе роли успешно запустились, во вкладке **«Эксперты»**. [Настройки алгоритмической торговли MT5](https://www.metatrader5.com/ru/terminal/help/startworking/settings)

## 4. Проверьте связь и выберите режим

Помощник на графике передаёт уведомления о торговых событиях локальному процессу Python. Контроллер использует их для внеочередной сверки и продолжает периодически проверять MT5. Уведомления работают без настройки в пульте. У торгового процесса RECOVERY обычный приоритет Windows. Окно пульта и служба, которая записывает состояние и квитанции команд, работают в двух отдельных процессах с пониженным приоритетом. Если служба пульта перезапустилась, проверьте состояние прежде, чем повторять неподтверждённую команду. Денежный результат доступен в истории счёта MT5. RECOVERY его не рассчитывает.

Если MT5 отклонил изменение STOP, прочитайте причину под номером ступени. Сообщение о прежней цене появляется после проверки действующего ордера. Если ордер уже исполнился, RECOVERY сверяет сделки в истории по его тикету. При сообщении «Сверка завершения цикла» новый вход приостановлен. RECOVERY сверяет закрытие цепочки по истории ордеров и сделок. После подтверждения пульт возвращается в «Готов к выбору режима» на паузе. Для следующего цикла нажмите «Старт» и выберите режим ожидания.

1. Откройте ярлык **«RECOVERY — Пульт управления»**. При первом запуске дождитесь **«MT5 — подключён»**. Сверьте показанные пультом счёт, сервер и символ. До команды запуска Python находится на паузе. Если «Старт» остаётся недоступным, проверьте сообщение в пульте, подключение к брокеру и пресеты на обоих графиках.
2. На паузе при пустом цикле откройте **«Настройки стратегии…»**. Начальная дистанция SL по умолчанию — **0.80**, порог переноса SL к цене входа — **0.40** в единицах цены инструмента. В окне указан размер лота для каждой из **24 ступеней**. Проверьте значения для своего символа и дождитесь подтверждения после сохранения.
3. Нажмите **«Старт»**. На новой установке дождитесь надписей **«Python — работает»** и **«Готов к выбору режима»**. Этого достаточно для проверки запуска. Когда захотите начать сопровождение на счёте, выберите режим.

   - **«Ждать рыночную позицию»**. Пульт покажет **«Ждёт ручную рыночную позицию»**. Стратегия может сразу подхватить уже открытую единственную ручную позицию по символу. После её полного ручного закрытия Python сам отменит оставшийся встречный STOP своей цепочки. При включённом повторе подтверждение отмены вернёт стратегию к ожиданию следующего ручного входа.
   - **«Ждать триггерный STOP»**. При отсутствии открытых позиций стратегия ищет один ручной **Buy Stop** или **Sell Stop**, который виден в MT5 по настроенному символу. Вы можете выставить его до или после выбора режима. Для ордера с сайта или из приложения брокера сверьте его тип во вкладке «Торговля» MT5.

Для выхода из ожидания используйте **«Отменить ожидание»**. Во время активного цикла **«Отключить повтор»** отключает будущий повторный подхват, а сопровождение текущего цикла продолжается. Для остановки используйте **«Стоп»**, когда пульт разрешит действие, и дождитесь подтверждения паузы.

После фактического исполнения RECOVERY проверяет защитный SL каждой привязанной позиции. Целевая дистанция от цены входа равна меньшему из двух значений — настройке «Дистанция SL» и 0,80 единицы цены. Более близкий SL и текущий TP сохраняются. Если брокер пока не допускает целевой уровень, помощник ждёт допустимой котировки. Исполнение самого SL может пройти с проскальзыванием.

Например, BUY STOP исполнился по 2500,30, а прежний SL равен 2499,20. При дистанции 0,80 помощник запросит SL 2499,50. Новый уровень действует с момента подтверждения брокером.

После выхода по SL поддержки у стратегии могут остаться два STOP — встречный и повторный в сторону закрытой позиции. Если оба полностью отменены до исполнения, RECOVERY сверяет историю обоих тикетов. Как только по символу нет позиций и ордеров и сверка завершена, пульт показывает «Готов к выбору режима» с выключенным повтором. Для следующего цикла выберите режим ожидания. Если Python после перезапуска на паузе, сначала нажмите «Старт».

## 5. Оставьте VPS в работе

Сохраните открытыми MT5 и два графика с помощниками. Для обычного отключения RDP закройте окно удалённого рабочего стола и оставьте сеанс Windows активным. Если на VPS настроен автоматический выход из отключённых сеансов, учтите эту политику. После перезагрузки войдите под тем же пользователем, запустите MT5 и пульт, сверьте счёт, обе роли, позиции и ордера, затем нажмите **«Старт»** для продолжения.
